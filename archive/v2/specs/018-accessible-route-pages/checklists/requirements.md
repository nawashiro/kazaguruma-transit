# Specification Quality Checklist: 認証・場所詳細・レート制限の専用ページ化

**Purpose**: 専用ページ化の要求が利用者価値、アクセシビリティ、既存操作、直接アクセス、戻り先の境界を十分に定義しているか確認する。
**Created**: 2026-08-14
**Feature**: [../spec.md](../spec.md)

## Content Quality

- [x] CHK001 仕様が、ダイアログ技術ではなく利用者が専用ページで達成する目的を記述している。
- [x] CHK002 ログイン、アカウント作成、場所詳細、レート制限の各利用者価値を独立したシナリオで記述している。
- [x] CHK003 既存の認証、場所データ、目的地設定、レート制限の意味を維持する境界を記述している。
- [x] CHK004 大規模なUIライブラリ移行、新認証方式、新永続化を対象外としている。

## Requirement Completeness

- [x] CHK005 各専用ページに主見出し、主要操作、読み込み中・成功・失敗・戻り導線の要求がある。
- [x] CHK006 ログインとアカウント作成の相互リンク、既存パスキー処理、入力エラー、キャンセルを要求している。
- [x] CHK007 場所詳細の直接アクセス、無効な識別子、詳細情報、目的地設定を要求している。
- [x] CHK008 レート制限ページがページ表示だけで検索や外部API要求を再実行しないことを要求している。
- [x] CHK009 認証とレート制限の戻り先を同一サイト内の許可済み遷移へ限定し、外部URLや任意return URLを拒否することを要求している。
- [x] CHK010 認証成功後は元の画面へ戻るだけとし、認証前の投稿・評価操作を自動再開しないことが確定している。`FR-006`。
- [x] CHK011 場所詳細URLの識別子を`/location-detail/[id]`のパスで渡すことが確定している。`FR-009`。

## Accessibility & UX

- [x] CHK012 ページタイトル、主見出し、主要ランドマーク、論理的な見出し順を要求している。
- [x] CHK013 フォーム操作の表示上およびプログラム上の名前を要求している。
- [x] CHK014 エラー・状態メッセージを日本語で利用者が確認できることを要求している。
- [x] CHK015 キーボードのみで主要操作、相互リンク、エラー表示へ到達できることを要求している。
- [x] CHK016 通常のリンク・ボタン・フォームを使い、ダイアログ専用のfocus trapやbackdropを必須にしない方針を明記している。

## Existing Behavior & Scope

- [x] CHK017 認証のパスキー名、規約同意、成功・失敗・キャンセルの意味を維持している。
- [x] CHK018 場所の説明、地域、提供情報、ライセンス、外部リンク、目的地設定を維持している。
- [x] CHK019 レート制限の閾値、時間窓、外部APIポリシーを変更しないことを明記している。
- [x] CHK020 Issue #67の作業単位1〜3の既存改善と主要操作の退行を防ぐ要求がある。

## Success Criteria & Testability

- [x] CHK021 直接アクセス、主導線、成功、失敗、戻り導線、キーボード操作を検証対象としている。
- [x] CHK022 レート制限ページ表示による重複要求を0件とする測定可能な基準がある。
- [x] CHK023 変更テスト、既存改善、主要操作の退行をSuccess Criteriaに含めている。
- [x] CHK024 仕様の未解決事項以外に、曖昧な必須要件や未記入プレースホルダーが残っていない。
- [x] CHK025 場所詳細の未知ID、重複・不正ID、データ取得失敗を別状態として表示・検証する要件がある。`FR-010`、`SC-007`。

## Notes

- 主要な仕様上の未解決事項は解消し、仕様を`Approved`とした。`Clarifications`、Requirements、Acceptance Scenarios、Assumptions、Out of Scopeの整合を再確認した。
- `plan.md`、`tasks.md`は作成済みの設計成果物としてレビュー・配送対象に含める。本番コードとテストコードは、tasksのRED・独立レビュー・実装・GREENゲートを満たすまで変更しない。
