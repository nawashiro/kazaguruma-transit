# Issue #98 仕様

**Issue:** [#98](https://github.com/nawashiro/kazaguruma-transit/issues/98)

## 背景

会話の編集を保存すると、保存成功メッセージが2秒だけ表示された後、自動的に会話詳細画面へ遷移する。利用者が成功メッセージを読み終える前に画面を見失うため、保存結果を確認できる明示的なリンクだけを提供する。

## ユーザーストーリー

### US1（P1）保存結果を確認してから詳細画面へ移動する

会話作成者として、編集保存後の成功メッセージを自分のタイミングで確認し、必要なときだけ会話詳細画面へ移動したい。そうすれば、一瞬の表示を見逃して保存結果に不安を感じずに済む。

## 受入基準

- **AC-1:** 編集保存が成功すると「会話が更新されました」を表示し続ける。
- **AC-2:** 保存成功後に時間経過だけを理由として `/discussions/{naddr}` へ自動遷移しない。
- **AC-3:** 保存成功画面に、現在の会話詳細 URL `/discussions/{naddr}` へ遷移するネイティブリンクを表示する。
- **AC-4:** 保存ボタン押下による署名・publish・成功表示の既存挙動を維持する。
- **AC-5:** 削除、会話一覧掲載申請、未認証時のログイン導線には変更を加えない。

## 非対象

- 保存するNostrイベントのタグ、署名、relay通信の変更
- 保存失敗時のエラー処理の変更
- 編集画面以外の自動遷移の一般的な見直し
- 新規永続化やデータモデルの変更

## アクセシビリティ確認

- リンクの目的が「会話画面に戻る」という可視名で分かること（WCAG 2.2 2.4.4）。
- 既存の `btn`、`text-base`、`min-h-[44px]`、`rounded-full dark:rounded-sm` の方針を維持すること（WCAG 2.2 2.5.8）。
