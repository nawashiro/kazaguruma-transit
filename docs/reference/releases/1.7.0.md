## バス停までの歩く範囲

- 経路候補のバス停を、碁盤目の街路を想定した補正(√2)のあとの徒歩距離が500メートル以内のものだけに絞り込みました。
- 最寄りバス停1か所だけを使う経路も同じ上限を守ります。最寄りバス停が上限を超えるときは、周辺のバス停を組み合わせた経路へ切り替えます。

## 周辺のバス停の一覧

- 半径内のバス停一覧が、先頭から10件だけを評価していた問題を直しました。すべてのバス停を評価して、指定した半径内のものを近い順に最大10件返します。
- 半径一覧と最寄りバス停の選択で使う距離を、経路検索と同じ直線距離(ハバーサイン)に統一しました。真に近い側のバス停が最寄りとして選ばれます。
