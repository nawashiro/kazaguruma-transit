## 場所の詳細

- 車いす情報を追加しました。OpenStreetMapの`wheelchair`タグを「全面」「一部」「非対応」「情報なし」の4状態で示し、WheelMapまたはOpenStreetMapの修正ページへ進めます。
- 基本情報を追加しました。電話、ウェブサイト、Wikipedia、営業状態、営業時間、OpenStreetMapの編集リンクを、値のあるものだけ表示します。
- 営業状態と先一週間の営業時間を表示します。日本時間で計算し、今日が祝日のときは注意を添えます。規則を解釈できないときは営業中かどうかを断定せず、元の規則を示します。
- 写真をビルド時にWebPへ変換し、画面の幅に合わせて480・960・1280pxの派生画像を配信します。原寸画像の取得をやめ、写真のあるページの通信量を減らしました。
- 作者の分からない写真とパブリックドメインの写真も表示します。作者不明はその旨を示し、ライセンスは記録された文字列を表示します。

## 場所の一覧

- 一覧と詳細の対象を、バス停から補正後の徒歩距離が500m以内の目的地に限定しました。一覧と経路検索で到達可能性の見積もりが揃います。
- カードに写真と車いすの状態を表示します。状態は色だけでなく、アイコンと文字でも示します。
- データ提供元の案内を追加しました。

## 目的地の選択

- 目的地に小学校8校と病院6施設を追加しました。
- 施設カテゴリの名前と並びを、公開データセットのカテゴリ語彙から決めるようにしました。データ側の追加や名前の変更が、アプリの修正なしに反映されます。
- 目的地の候補を、徒歩圏内の施設から作る目録（`data/destinations.json`）で管理するようにしました。

## 運行情報

- 入力画面とPDFの案内を、千代田区公式LINEから、風ぐるま公式のバスロケーションシステム（BusGO!）へ替えました。

## 互換性のない変更

### 設定ファイル

`app-config.json`の場所データの取得先が変わりました。

- 追加: `datasetJsonLdUri`、`osmMirrorUri`、`wikidataMirrorUri`
- 削除: `mainFacilitiesUri`、`keyLocationsUri`、`locationsDataVersion`

追加した3項目がないと、ビルドは失敗します。`app-config.json.example`を元に設定し直してください。取得先を変えたときは、`npm run update-destinations`で`data/destinations.json`を再生成してください。目録の`source`が設定と一致しないときも、ビルドは失敗します。

### 公開URL

- カテゴリのURLを、英語のスラッグから`gif-poi`コード4桁（例: `/locations/0801`）へ変えました。
- 場所詳細のURLを、`urn:uuid:`のIDをURLエンコードした形へ変えました。
- 旧URLからのリダイレクトは用意していません。旧URLは404を返します。

### ビルド

- ビルドは公開グラフ、OSMタグミラー、Wikidataミラー、Wikimedia Commonsからデータを取得します。ネットワーク接続が必要です。
- 写真の変換に`sharp`を使います。派生画像は`public/generated/location-images/`へ出力し、リポジトリとDockerのビルド文脈には含めません。
- アプリの実行時には、場所データを外部へ取りに行きません。
