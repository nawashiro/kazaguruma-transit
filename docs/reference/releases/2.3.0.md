## 地点検索

- 住所検索とGPSの逆引きを、Google Maps Geocoding APIから自前の索引へ移しました。データは国土交通省の位置参照情報とOpenStreetMapです。実行時に外部へ問い合わせません。
- 住所欄は打鍵に追従して候補を出します。日本語入力の変換中は送らず、遅れて届いた古い応答は捨てます。
- 地点検索の利用制限を外しました。入力中に429の画面へ飛び、打ちかけの文字が消えることがなくなります。

## 徒歩距離と経路の選択

- 徒歩距離を、直線距離に√2を掛ける近似から、実際の歩行ネットワーク上の経路長へ置き換えました。徒歩時間と最寄り停留所の選択が変わります。
- 徒歩優先では乗換1回を10分として比べます。「なるべく歩きたくない」を選んでも乗換のある経路が案内されていた問題を直しました。
- 結果画面が徒歩時間に足していた5分を削除しました。3mの徒歩を7分と表示していました。

## 印刷用PDFの地図

- 地図をOpenFreeMapのベクタタイルとMapLibreへ移し、`GOOGLE_MAPS_API_KEY`を不要にしました。
- 地図はモノクロで描きます。徒歩区間は歩行ネットワークの折れ線を実線で描き、地図を描けなければPDFを返しません。

## データとアップグレード

- 索引と徒歩ネットワークはリポジトリで管理します。クローンしただけで検索と経路案内が動きます。
- `GOOGLE_MAPS_API_KEY`を`.env.local`と`.env`から外せます。
- 検索結果が変わります。徒歩優先で返る経路が変わり、乗換が減って到着が遅くなる場合があります。
