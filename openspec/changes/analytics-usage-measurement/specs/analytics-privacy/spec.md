# Spec Delta

## ADDED Requirements

### Requirement: GAへ送信するイベントパラメーターの制限

GAへ送るイベントパラメーターには、座標、住所、停留所名、利用者が入力した文字列を含めてはならない（MUST NOT）。計測には、項目名、種別、結果、件数、経過時間だけを送る。

#### Scenario: 地点を確定して検索する

- **WHEN** 利用者が住所検索・GPS・施設選択で地点を確定し、経路検索する
- **THEN** 送信されるイベントパラメーターに座標・住所・停留所名・入力文字列が含まれない

#### Scenario: 運営者のブラウザを識別する

- **WHEN** 運営者が`?owner=1`で識別を有効にする
- **THEN** 送信する識別用パラメーターは内部トラフィックと開発者トラフィックを示す値だけで、個人を識別する値を含まない
