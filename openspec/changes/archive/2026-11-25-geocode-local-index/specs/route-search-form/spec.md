# Spec Delta

## MODIFIED Requirements

### Requirement: 住所の確定と個別の再編集

住所検索は候補一覧を表示し、利用者が選んだ候補だけを採用しなければならない（SHALL）。候補が1件のときも同じ選択を経る。確定後は同じfieldset内に住所表示と「なおす」を提供しなければならない（SHALL）。「なおす」は該当地点だけを編集状態に戻す。再編集を始めた地点は再確定するまで最終検索に使用せず、入力画面に全体リセットを置かない。

#### Scenario: 複数の住所検索結果を受け取る

- **WHEN** 名前で検索し、複数の候補が返る
- **THEN** 候補をそれぞれ名前と住所で識別できる一覧として表示する
- **THEN** 利用者が選んだ候補の住所と座標だけを確定する

#### Scenario: 候補が1件だけ返る

- **WHEN** 名前で検索し、候補が1件だけ返る
- **THEN** その候補を一覧に表示し、利用者が選んだときに確定する

#### Scenario: 候補を選ばずに別の操作をする

- **WHEN** 候補一覧を表示したまま、ほかの入力グループやフォームを操作する
- **THEN** 候補一覧は地点を確定せず、以前の地点の状態を変えない

#### Scenario: 確定した住所を直す

- **WHEN** 利用者が目的地の「なおす」を押す
- **THEN** 目的地を再入力でき、出発地・日時・優先条件は変わらない
- **THEN** 目的地を再確定するまで以前の座標で最終検索されない

#### Scenario: 住所検索が失敗する

- **WHEN** 検索結果がない、または住所検索に失敗する
- **THEN** 該当地点の入力と関連付けたエラーを表示し、入力内容とほかの条件を保持する

### Requirement: 入力画面のスタイルと名前

入力画面は既存テーマと背景・枠線付きのfieldsetを使い、確定住所を別カードにしない構成で表示しなければならない（SHALL）。ルビ以外の利用者向け文字は算出サイズ16px以上とする。可視ラベルのあるGPS・日時・優先条件はそのラベルをアクセシブルな名前に使い、エラー説明の関連付けは保持する。「なおす」と「端末のGPSを許可する」は内容に応じた幅とし、親の幅いっぱいに引き伸ばさない。44 CSS px以上の操作領域を保つ。候補一覧の各項目も44 CSS px以上の操作領域を持ち、キーボードで選択でき、可視フォーカスを示す。

#### Scenario: フォームを表示して読み上げる

- **WHEN** 初期状態または住所確定後のフォームを表示する
- **THEN** 各グループを区別でき、住所のための追加カードは生成されない
- **THEN** GPS・日時・優先条件の名前は可視ラベルと一致し、エラーがあれば該当項目から参照できる
- **THEN** ライト・ダークの両テーマで文字サイズ条件を満たす

#### Scenario: 候補一覧をキーボードで操作する

- **WHEN** 住所検索の候補一覧を表示し、キーボードで移動して選択する
- **THEN** 各候補は44 CSS px以上の操作領域と可視フォーカスを持つ
- **THEN** 選択した候補が確定し、フォーカスが確定住所へ移る

#### Scenario: 再編集とGPSの補助操作を表示する

- **WHEN** 狭い画面または広い画面で「なおす」と「端末のGPSを許可する」を表示する
- **THEN** ボタンは内容に応じた幅で表示され、親要素の幅いっぱいに引き伸ばされない
- **THEN** 44 CSS px以上の操作領域と可視フォーカスを保ち、ラベルが必要に応じて折り返しても欠けない

### Requirement: GPSと目的地リンクの継続利用

GPS取得は「端末のGPSを許可する」というボタンから開始し、施設詳細から渡された目的地も確定済みの地点として利用できなければならない（SHALL）。GPSで座標を取得できた場合、住所の逆引きだけが失敗しても座標を出発地として使えるようにする。

#### Scenario: GPSを使用する

- **WHEN** 利用者が「端末のGPSを許可する」を押し、位置情報を取得できる
- **THEN** 出発地を確定し、ほかの条件を保持する
- **THEN** 住所の逆引きに失敗した場合は座標を表示して続行できる

#### Scenario: GPS取得を拒否する

- **WHEN** 位置情報の利用を拒否する、または取得に失敗する
- **THEN** 出発地に取得失敗を表示し、名前による検索を利用できる

#### Scenario: 施設詳細から入力画面を開く

- **WHEN** 有効な既存形式の目的地パラメーター付きリンクで入力画面を開く
- **THEN** 指定された目的地と「なおす」を表示し、ほかの入力グループも最初から表示する
