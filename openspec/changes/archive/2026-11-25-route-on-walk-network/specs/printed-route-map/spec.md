# Spec Delta

## MODIFIED Requirements

### Requirement: 地図上への徒歩区間の描画

PDFの地図は、出発地から乗車停留所までと、降車停留所から目的地までの徒歩区間を描かなければならない（MUST）。徒歩ネットワークから得た折れ線を実線で描く（MUST）。折れ線がないときだけ、始点と終点を結ぶ破線を描く（MUST）。破線は実在の歩行経路と読み違えられない線種とする。

#### Scenario: 徒歩区間を描く

- **WHEN** 出発地と乗車停留所の座標がある経路のPDFを生成する
- **THEN** その2地点の間の徒歩経路を実線で描く
- **THEN** 始点と終点を、地名のラベルで識別できる

#### Scenario: 折れ線がない

- **WHEN** 徒歩区間の座標はあるが折れ線がない経路のPDFを生成する
- **THEN** その2地点の間に破線を描く
- **THEN** 破線を実在の歩行経路として描かない

#### Scenario: 座標が欠けている

- **WHEN** 出発地または停留所の座標がない
- **THEN** その区間の地図を描かず、経路本文だけをPDFに含める

### Requirement: 徒歩経路座標の受け口

PDF生成の要求は、徒歩区間の折れ線を任意の項目として受け付けなければならない（MUST）。折れ線がある場合はその線を実線で描き、ない場合は始点と終点を結ぶ破線を描く。折れ線の有無で、地図以外のPDFの内容を変えてはならない（MUST NOT）。

#### Scenario: 折れ線を渡す

- **WHEN** 徒歩区間の折れ線を付けてPDFを生成する
- **THEN** 地図はその折れ線に沿った実線を描く

#### Scenario: 折れ線を渡さない

- **WHEN** 折れ線を付けずにPDFを生成する
- **THEN** 地図は始点と終点を結ぶ破線を描く
- **THEN** 経路、時刻、乗換、メモの内容は折れ線を渡した場合と同じになる
