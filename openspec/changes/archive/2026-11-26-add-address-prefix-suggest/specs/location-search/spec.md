# Spec Delta

## ADDED Requirements

### Requirement: 住所の途中入力に対する段階的な候補

住所として解釈できる入力に対して、候補は町名・丁目・街区のうち入力が示す段階より一つ下の段階で返さなければならない（MUST）。候補は入力の途中でも返さなければならない（MUST）。返す候補はすべて街区代表点を持つ住所とし、街区符号を持たない町名だけの住所を返してはならない（MUST NOT）。

町名の接頭辞が複数の町に一致するときは、住所としての候補を返してはならない（MUST NOT）。一つの町に決まったときだけ、その町の下位の段階を返さなければならない（MUST）。

#### Scenario: 町名を打ち終えたとき

- **WHEN** 利用者が`千代田区神田和泉町`を検索する
- **THEN** `千代田区神田和泉町1番`、`千代田区神田和泉町2番`、`千代田区神田和泉町3番`を候補として返す

#### Scenario: 町名の途中を打ったとき

- **WHEN** 利用者が`千代田区神田和`を検索し、この接頭辞を持つ町が神田和泉町だけである
- **THEN** 神田和泉町の街区を候補として返す

#### Scenario: 丁目を持つ町名を打ち終えたとき

- **WHEN** 利用者が`千代田区霞が関`を検索する
- **THEN** 一丁目・二丁目・三丁目それぞれの代表街区を候補として返す

#### Scenario: 丁目まで打ったとき

- **WHEN** 利用者が`千代田区霞が関1`を検索する
- **THEN** 霞が関一丁目の街区を候補として返す

#### Scenario: 複数の町に割れる語

- **WHEN** 利用者が`神田`を検索し、この接頭辞が28町に一致する
- **THEN** 住所としての候補を返さず、名前索引の候補だけを返す

#### Scenario: 絞りきれない区名

- **WHEN** 利用者が`千代田区`だけを検索する
- **THEN** 住所としての候補を返さない

### Requirement: 住所候補と名前候補の並び

住所としての候補と名前索引の候補は、一つの候補一覧に併せて返さなければならない（MUST）。住所候補は駅・公園・公共施設・文化施設・医療機関と同じ優先度に置かなければならない（MUST）。同じ優先度の中では、住所の一致を完全一致、前方一致の順に扱い、住所候補の町名が入力と一致するときは名前索引の部分一致より先に並べなければならない（MUST）。

#### Scenario: 住所と同名の名前がある

- **WHEN** 利用者が`隼町`を検索する
- **THEN** 隼町1番から4番までの住所候補を先に並べ、隼町の名前候補を後に並べる

#### Scenario: 同じ町名の駅がある

- **WHEN** 利用者が`麹町`を検索する
- **THEN** 完全一致した麹町の地点を先頭に置き、麹町の丁目の住所候補を続ける

#### Scenario: 住所が候補の残りを埋める

- **WHEN** 利用者が`霞が関`を検索し、名前索引の候補が5件に満たない
- **THEN** 霞が関の丁目の住所候補で残りを埋める

## MODIFIED Requirements

### Requirement: 番地は住所索引で解決する

番地を含む住所の検索は、住所索引の街区代表点で解決しなければならない（MUST）。OSMの`addr:*`タグだけを番地の正として扱ってはならない（MUST NOT）。数字の並びは町の構造に従って読み、丁目を持つ町では1つ目を丁目、2つ目以降を街区として扱わなければならない（MUST）。丁目を持たない町では1つ目を街区として扱わなければならない（MUST）。街区より後ろの数字は住所の解決に使ってはならない（MUST NOT）。

#### Scenario: 丁目を持つ町名の番地を検索する

- **WHEN** 利用者が`霞が関1-1`を検索する
- **THEN** 霞が関一丁目1番の代表点を返す

#### Scenario: 丁目を持たない町名の番地を検索する

- **WHEN** 利用者が`神田和泉町1`を検索する
- **THEN** 神田和泉町1番の代表点を返し、一丁目として解釈しない

#### Scenario: 漢数字と全角数字を受け付ける

- **WHEN** 利用者が`霞が関一丁目1番`または`霞が関１−１`を検索する
- **THEN** `霞が関1-1`と同じ代表点を返す

#### Scenario: 区名を伴う住所を検索する

- **WHEN** 利用者が`千代田区神田和泉町1番地`を検索する
- **THEN** 区名を除いた住所として解決し、神田和泉町1番の代表点を返す

#### Scenario: 街区のあとに号を伴う住所を検索する

- **WHEN** 利用者が`隼町4-1`を検索する
- **THEN** 隼町4番の代表点を返し、1番とは解釈しない

#### Scenario: 丁目と街区と号を伴う住所を検索する

- **WHEN** 利用者が`霞が関1-1-1`を検索する
- **THEN** 霞が関一丁目1番の代表点を返す

#### Scenario: 存在しない街区を指定する

- **WHEN** 利用者が町名は実在するが街区符号が存在しない番地を検索する
- **THEN** その町名の代表点を候補として返し、存在しない街区を断定しない

### Requirement: 別名と表記ゆれによる照合

索引の各地点は、名前と、記録されている場合は公式名称・別名・短縮名・日本語名でも照合できなければならない（MUST）。検索語の末尾が「駅」で索引に一致しない場合は、「駅」を除いた語で再照合しなければならない（MUST）。検索語の先頭が`東京都`または`千代田区`のときは、それを除いた語でも再照合しなければならない（MUST）。

#### Scenario: 別名で検索する

- **WHEN** 利用者が`東京復活大聖堂`または`ニコライ堂`を検索する
- **THEN** どちらも同じ地点を候補に含める

#### Scenario: 駅を付けて検索する

- **WHEN** 利用者が`四ツ谷駅`を検索し、索引に`四ツ谷駅`が無く`四ツ谷`がある
- **THEN** 末尾の「駅」を除いた語で再照合し、`四ツ谷`を候補に含める

#### Scenario: 区名を付けて名前を検索する

- **WHEN** 利用者が`千代田区神田和泉町`を検索し、名前索引に`千代田区神田和泉町`が無く`神田和泉町`がある
- **THEN** 区名を除いた語でも照合し、`神田和泉町`を候補に含める

#### Scenario: 区名から始まる名前を検索する

- **WHEN** 利用者が`千代田区役所`を検索する
- **THEN** 区名を除いた`役所`だけでなく、元の語でも照合し、`千代田区役所`を候補に含める

### Requirement: 候補の順位付け

候補は、種別に応じた優先度で並べなければならない（MUST）。駅、公園、公共施設、文化施設、医療機関、住所を上位とし、物販、飲食、駐車場を下位とする（MUST）。同じ優先度のときは、名前の一致が完全一致、前方一致、部分一致の順に並べる（MUST）。

#### Scenario: 同名の地点が多い名前を検索する

- **WHEN** 利用者が`ファミリーマート`を検索する
- **THEN** チェーン店の候補は公共施設より後ろに並ぶ

#### Scenario: 駅と停留所が同じ語に一致する

- **WHEN** 利用者が`神田`を検索する
- **THEN** 駅を停留所や店舗より上位に並べる

#### Scenario: 完全一致を優先する

- **WHEN** 利用者が`千代田区役所`を検索し、完全一致の地点と部分一致の地点がある
- **THEN** 完全一致の地点を先に並べる

#### Scenario: 住所を上位に置く

- **WHEN** 利用者が`霞が関`を検索し、住所候補と物販の候補がある
- **THEN** 住所候補を物販の候補より先に並べる
