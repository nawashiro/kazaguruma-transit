# Spec Delta

## MODIFIED Requirements

### Requirement: 徒歩経路の折れ線

徒歩距離を求めたとき、その経路のうち道の上を通る部分の折れ線を`[経度, 緯度]`の配列として取り出せなければならない（MUST）。折れ線は通過したノードの座標だけを順に並べ、起点と到着点そのものを含めない（MUST）。起点と到着点から最寄りノードまでの接続区間は徒歩距離にだけ含め、折れ線には含めない（MUST）。経路検索の結果は、出発地から乗車停留所までと、降車停留所から目的地までの折れ線をPDF生成へ渡さなければならない（MUST）。

#### Scenario: 折れ線を取り出す
- **WHEN** 出発地から乗車停留所までの徒歩距離を求める
- **THEN** 通過したノードの座標だけを順に並べた座標列が得られる
- **THEN** 出発地そのものの座標は座標列に含まれない

#### Scenario: 乗り降りの地点から同じノードに接続する
- **WHEN** 降車停留所と目的地の最寄りノードが同じ1点である徒歩距離を求める
- **THEN** 折れ線はそのノード1点だけになる
- **THEN** 徒歩距離は両端の接続区間を含む値のまま変わらない

#### Scenario: PDFへ渡す
- **WHEN** 経路のある検索結果からPDFを生成する
- **THEN** 徒歩区間の折れ線がPDF生成の要求に含まれる
