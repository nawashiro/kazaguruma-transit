# Spec Delta

## ADDED Requirements

### Requirement: 候補一覧の見出しと件数の省略

住所検索の候補一覧は入力欄の直下に置き、見出しと件数を画面に表示してはならない（MUST NOT）。一覧は地点の種類が分かる名前、たとえば「目的地の候補」を持ち（MUST）、候補が現れたことは件数だけを支援技術へ通知する（MUST）。通知の文言は画面に表示しない（MUST NOT）。

#### Scenario: 候補を表示する

- **WHEN** 住所欄に入力して候補が返る
- **THEN** 入力欄の直下に候補の一覧だけが並び、見出しの行も件数の行も表示されない
- **THEN** 一覧の名前は「目的地の候補」または「出発地の候補」である

#### Scenario: 候補が出たことを読み上げる

- **WHEN** 支援技術で画面を読み上げている状態で候補が表示される
- **THEN** 候補の件数が通知され、件数の文言は画面上に表示されない

### Requirement: 候補項目の操作可能性の提示

候補一覧の各項目は、ポインターを重ねると背景色が変わり、ポインターの形が指になる（MUST）。背景色の変化は入力グループの地色に対して見て分かる差を持つ（MUST）。キーボードのフォーカス表示は従来どおり保つ（MUST）。

#### Scenario: 候補にポインターを重ねる

- **WHEN** 候補一覧の項目にポインターを重ねる
- **THEN** 項目の背景色が入力グループの地色から変わり、ポインターの形が指になる
- **THEN** 項目の文字と名前・住所は読み取れるままである

#### Scenario: キーボードで候補へ移動する

- **WHEN** キーボードで候補一覧の項目へ移動する
- **THEN** 可視フォーカスが表示される

### Requirement: 住所欄の補足文

目的地と出発地の住所欄は、入力の前に「住所か建物名を入力してください。」を示さなければならない（MUST）。補足文は入力欄の説明として関連付け、エラーがあるときはエラーと併せて読めるようにする（MUST）。

#### Scenario: 住所欄を表示する

- **WHEN** 目的地または出発地の入力欄を表示する
- **THEN** 入力欄の説明に「住所か建物名を入力してください。」が入る

#### Scenario: 入力のエラーと併せて読む

- **WHEN** 候補が見つからないまま入力欄を離れる
- **THEN** エラーの文言と補足文の両方が入力欄から参照できる

### Requirement: 入力グループの見出しの文字サイズ

入力画面の「目的地」「出発地」「日時」「優先条件」の見出しは、本文より大きく20pxで表示しなければならない（MUST）。「名前で検索」と「よく利用される施設から選択」の小見出しは18pxで表示し（MUST）、本文の16pxに対して階層を作る（MUST）。いずれも見出しの文字として一貫した太さで表示する（MUST）。

#### Scenario: 見出しを本文より大きく表示する

- **WHEN** 入力画面を表示する
- **THEN** 4つの入力グループの見出しは20pxで表示される
- **THEN** 「名前で検索」と「よく利用される施設から選択」は18pxで表示される

#### Scenario: 見出しの階層を保つ

- **WHEN** 見出しと本文を並べて表示する
- **THEN** グループの見出し、小見出し、本文の順に文字が小さくなり、本文は16pxを下回らない
