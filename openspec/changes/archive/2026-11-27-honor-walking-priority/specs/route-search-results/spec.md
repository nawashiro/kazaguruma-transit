# Spec Delta

## ADDED Requirements

### Requirement: 出発地と目的地の表示時刻

結果画面の出発地と目的地の時刻は、経路検索が徒歩ネットワークから求めた徒歩時間だけを、乗降時刻に加減して表示しなければならない（MUST）。徒歩時間へ固定の余裕を足してはならない（MUST NOT）。徒歩時間が得られないときは、乗降時刻をそのまま表示する。

#### Scenario: 徒歩時間が1分の停留所を表示する

- **WHEN** 出発地から3メートルの乗車停留所があり、徒歩時間が1分である
- **THEN** 乗車時刻の1分前を出発地の時刻として表示する。固定の5分を足した6分前は表示しない

#### Scenario: 徒歩時間がない停留所を表示する

- **WHEN** 乗車停留所までの徒歩時間が得られない
- **THEN** 乗車時刻をそのまま出発地の時刻として表示する
