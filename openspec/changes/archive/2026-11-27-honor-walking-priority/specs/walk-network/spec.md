# Spec Delta

## MODIFIED Requirements

### Requirement: 徒歩距離の定義

徒歩距離は、起点から徒歩ネットワークの最寄りノードまでの直線距離、そのノードから到着点の最寄りノードまでのネットワーク上の最短距離、到着点の最寄りノードから到着点までの直線距離の和としなければならない（MUST）。起点と到着点の最寄りノードが同じときは、和ではなく2点間の直線距離としなければならない（MUST）。直線距離に係数を掛けた近似を徒歩距離として使ってはならない（MUST NOT）。到着点が停留所のときは、停留所の座標までの接続区間を含める。

#### Scenario: 道の上にある2地点の距離

- **WHEN** 2地点のどちらも徒歩ネットワークのノードの上にある
- **THEN** 徒歩距離はネットワーク上の最短距離になる

#### Scenario: 道から離れた地点の距離

- **WHEN** 出発地が建物の中にあり、最寄りのノードまで40メートルある
- **THEN** 徒歩距離は40メートルとネットワーク上の距離の和になる

#### Scenario: 直線距離の補正を使わない

- **WHEN** 徒歩距離を求める
- **THEN** 直線距離に√2を掛けた値を距離として返さない

#### Scenario: 2地点が同じノードに接続する

- **WHEN** 出発地から3メートル離れた停留所を求める
- **THEN** 徒歩距離は3メートルになり、同じ接続区間を2回足さない

#### Scenario: 同じノードへの補正が500メートル判定を変えない

- **WHEN** 500メートル以内の停留所がある地点で、同じノードへ接続する停留所までの距離を求める
- **THEN** 徒歩距離は補正前以下になる
- **THEN** 補正によって500メートルを超える停留所は生じない

### Requirement: 徒歩経路の折れ線

徒歩距離を求めたとき、その経路のうち道の上を通る部分の折れ線を`[経度, 緯度]`の配列として取り出せなければならない（MUST）。折れ線は通過したノードの座標だけを順に並べ、起点と到着点そのものを含めない（MUST）。起点と到着点から最寄りノードまでの接続区間は折れ線に含めない（MUST）。経路検索の結果は、出発地から乗車停留所までと、降車停留所から目的地までの折れ線をPDF生成へ渡さなければならない（MUST）。

#### Scenario: 折れ線を取り出す

- **WHEN** 出発地から乗車停留所までの徒歩距離を求める
- **THEN** 通過したノードの座標だけを順に並べた座標列が得られる
- **THEN** 出発地そのものの座標は座標列に含まれない

#### Scenario: 乗り降りの地点から同じノードに接続する

- **WHEN** 降車停留所と目的地の最寄りノードが同じ1点である徒歩距離を求める
- **THEN** 折れ線はそのノード1点だけになる
- **THEN** 徒歩距離は2点間の直線距離になる

#### Scenario: PDFへ渡す

- **WHEN** 経路のある検索結果からPDFを生成する
- **THEN** 徒歩区間の折れ線がPDF生成の要求に含まれる
