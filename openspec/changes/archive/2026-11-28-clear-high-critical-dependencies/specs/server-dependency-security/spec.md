# Spec Delta

## MODIFIED Requirements

### Requirement: 公開サーバー依存の修正版を使用する

配布物は Server Actions のサービス拒否（GHSA-p3m5-59mp-jv5r）と画像処理の任意コード実行（GHSA-2464-fhr4-w9xw）、Next.js の画像最適化における SVG 拒否の迂回（GHSA-7qx7-33qx-rqx2）について、公開情報の修正条件を満たす依存を使用しなければならない（MUST）。PDF 印刷地図に使う maplibre-gl は、`DOM.sanitize()` の XSS（GHSA-jrc7-96c5-q579）の修正版以上でなければならない（MUST）。依存宣言と配布物の解決結果の両方を確認する。

#### Scenario: 修正版へ更新する

- **WHEN** 更新後の依存をロックファイルから導入する
- **THEN** 宣言下限と解決値が対象脆弱性の修正条件を満たす
- **AND** 同じ対象の脆弱性が依存監査に残らない

#### Scenario: 古い依存へ後退する

- **WHEN** 宣言下限または解決値が対象の修正版を下回る
- **THEN** 依存の検査が失敗する

#### Scenario: 修正版のない深刻度の高い警告が残る

- **WHEN** 依存監査が、修正版の存在しない high または critical の警告を、公開サーバーから到達できる依存に報告する
- **THEN** その依存を上位の系列へ移行し、修正版を含む系列で解決する
- **AND** 監査の提示する後退版を採用しない

## ADDED Requirements

### Requirement: 監査の high と critical を残さない

依存監査は、全依存について high と critical の警告を0件にしなければならない（MUST）。中程度以下の警告が残る場合は、その依存経路と実害の有無を作業記録に残す（MUST）。

#### Scenario: ロックファイルから導入して監査する

- **WHEN** 作業者がロックファイルから依存を導入し、依存監査を実行する
- **THEN** high と critical の警告は0件になる
- **AND** 中程度以下の警告が残れば、その経路と評価を作業記録に書く

#### Scenario: 深刻度が下がらない依存が残る

- **WHEN** 修正版へ上げても high または critical の警告が残る
- **THEN** 作業者は解消できない理由と残存する経路を作業記録に書く
- **AND** 全警告を解消したと報告しない

### Requirement: 依存の解決値を検査で固定する

検査は、監査で消した依存の解決値が修正版を下回らないことを、依存を導入した状態で確かめなければならない（MUST）。宣言下限だけを読み、導入した解決値を確かめない検査にしてはならない（MUST NOT）。

#### Scenario: 解決値が修正版を下回る

- **WHEN** 導入した依存の解決値が、対象脆弱性の修正版を下回る
- **THEN** 検査が失敗する

#### Scenario: 宣言だけを書き換えて解決値が古い

- **WHEN** 宣言の下限だけが修正版を満たし、導入した解決値が古いままである
- **THEN** 検査が失敗し、ロックファイルの更新を促す

### Requirement: 地図ライブラリの移行後も PDF の地図を描く

PDF 生成のページへの地図ライブラリの読み込みは、配布物の形式に依存せず、地図を描ける状態にしなければならない（MUST）。ライブラリを読み込めない、または地図を描けないときは、地図を欠いた PDF を返さずにエラー応答を返す（MUST）。

#### Scenario: 地図を含む PDF を生成する

- **WHEN** 経路のある検索結果から PDF を生成する
- **THEN** 地図はライブラリの読み込み後に描かれる
- **AND** 描いた地図の画像は白紙でなく、モノクロの濃淡を持つ

#### Scenario: ライブラリを読み込めない

- **WHEN** 地図ライブラリの読み込みに失敗する
- **THEN** システムは PDF を返さずにエラー応答を返す
- **AND** 地図を欠いた PDF を地図入りの PDF として渡さない
