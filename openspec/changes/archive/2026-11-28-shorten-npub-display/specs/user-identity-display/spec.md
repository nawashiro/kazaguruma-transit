# Spec Delta

## Purpose

利用者のNostr公開鍵（npub）を画面に出すとき、読み手に読ませる値を最小限の長さに抑え、全体が必要なときはコピーで取り出せるようにする。npubは63文字あり、どの部分を読んでも人物の区別は付かず、狭い画面ではほかの情報を押し出す。

## ADDED Requirements

### Requirement: npub表示の長さ

画面に表示するnpubは、先頭の `npub1` とそれに続く4文字までに限らなければならない（MUST）。画面幅に余裕があるときは、先頭9文字に省略記号 `…` を付けた10文字で表示する。npub全体を表示してはならない（MUST NOT）。短縮は画面表示にだけ適用し、コピーする値、Nostrイベントに載せる値、APIが返る値はnpub全体のままとする（MUST）。

#### Scenario: 長いnpubの表示

- **WHEN** 63文字のnpubを表示する
- **THEN** 先頭9文字に `…` を付け、`npub1ef93…` の10文字で表示する

#### Scenario: 9文字のnpubの表示

- **WHEN** 9文字以下のnpubを表示する
- **THEN** 先頭9文字の上限に収まるので、`…` を付けずにそのまま表示する

#### Scenario: 幅が足りないとき

- **WHEN** `npub1ef93…` の10文字が収まらない幅で表示する
- **THEN** 行がはみ出さないよう `npub1` 以降が途中で切れてよい。`…` まで見えないことを欠陥としない

#### Scenario: 短縮後のコピー

- **WHEN** 短縮表示のコピー操作をする
- **THEN** クリップボードにはnpub全体が入る

#### Scenario: 16進数の公開鍵の表示

- **WHEN** 16進数の公開鍵を表示する
- **THEN** npubに変換したうえで、同じ長さの規則で表示する

### Requirement: 読み上げ名のnpub使用

ボタンやチェックボックスの読み上げ名に、npubや16進数の公開鍵をそのまま入れない（MUST）。利用者を指す読み上げ名は、同じ画面に出ている日本語の呼び名を使う（MUST）。

#### Scenario: モデレーターの削除ボタン

- **WHEN** 会話の作成・編集画面で、モデレーターの削除ボタンを読み上げる
- **THEN** 「モデレーター」と日本語の呼び名、「を削除」を読む。npubは読まない

#### Scenario: 同じ呼び名の利用者が並ぶ

- **WHEN** 日本語の呼び名が同じモデレーターが2人並び、削除ボタンを読み上げる
- **THEN** 読み上げ名は同じになる。画面の並び順で対象を選ぶ
