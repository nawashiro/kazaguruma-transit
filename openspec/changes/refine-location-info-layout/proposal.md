# Proposal

## Why

場所詳細のバリアフリー情報は、車いすの状態と外部リンクが1つの見出しに混在している。ルビ表示を有効にすると状態バッジの文言が折り返され、WheelMapへの参照ボタンも文字が上に寄る。営業時間は独立したセクションとして基本情報から離れ、一覧の先頭が「11/18(水)」のままである。一覧カードの写真帰属も2行に分かれて読みにくい。

情報のまとまりと表示の安定性を整え、利用者が状態・営業時間・出典を短い視線移動で確認できるようにする。

## What Changes

- 場所詳細のバリアフリー情報を「車いす情報」と「バリアフリー情報」に分ける。車いす情報は状態バッジ・説明文・WheelMapまたはOpenStreetMapの参照リンクを持ち、バリアフリー情報は言葉の道案内や東京バリアフリーマップなどの外部リンクだけを持つ。外部リンクがないときはバリアフリー情報の見出しを出さない。
- 状態バッジと説明文を横一列に並べる。状態が情報なしのときの説明文は「追加してください。」に変え、バッジの「情報なし」との重複をなくす。
- 参照リンクの可視文言を「編集する（WheelMapを開きます）」または「追加する（WheelMapを開きます）」に変え、「詳細を見る」を外す。ボタンはルビ表示の対象から外し、上下の余白を標準のボタン中央揃えに戻す。
- 営業時間を基本情報の中へ移し、「営業状態」と「営業時間」の2行に分ける。営業状態の行は状態バッジ、次に変わる時刻、今日が祝日のときは祝日の警告、目安の注意書きを持ち、営業時間の行は一週間の一覧と目安の注意書きを持つ。営業状態を解釈できないときは、祝日の警告を出さず、規則と目安の注意書きだけを出す。独立した営業時間セクションは置かない。
- 一週間の一覧の先頭は、日付と曜日の代わりに「今日」と表示する。
- 一覧カードの写真帰属を「写真 作者・ライセンス」の1行にまとめる。ライセンスは引き続きテキストとし、詳細ページだけがリンクを持つ。
- 状態バッジと操作ボタンをルビ表示の対象外にし、バッジの文言を折り返さない。営業時間の一覧の日付・曜日・時間帯にはルビを付けない。文章にはこれまでどおりルビを適用する。
- 「提供」セクションをなくし、車いす情報と基本情報の操作ボタンの後に「© OpenStreetMap contributors ODbL-1.0」を表示する。
- 場所一覧では、状態が「情報なし」の場所にも無彩色のバッジを表示する。バッジの表示条件をなくし、すべての場所で同じ構造にする。
- 編集リンクを画面上部から基本情報の情報行の後ろ（出典の前）へ移し、左寄せに統一する。
- セクション間の余白を広げ、見出しの切れ目を分かりやすくする。
- `docs/how-to/update-location-data.md` の営業時間の配置、画像帰属、情報なしの案内、出典の表示位置を新しい表示に合わせる。

## Capabilities

### New Capabilities

なし。

### Modified Capabilities

- `location-ui`: 車いす情報とバリアフリー情報の分割、バッジと説明の横並び、営業時間の行、ルビ表示との干渉防止、写真帰属の1行化。
- `wheelchair-accessibility`: 情報なしの案内文、参照リンクの文言、車いす情報セクションでの表示。
- `opening-hours`: 基本情報内の営業状態・営業時間の行、一覧先頭の「今日」表示。
- `location-facts`: 編集リンクの基本情報内への移動と左寄せ、基本情報の表示条件。

## Impact

- 変更: `src/components/features/BarrierAccessibility.tsx`、`src/app/locations/location-detail/[id]/page.tsx`、`src/lib/location/wheelchair-status.ts`、`src/app/locations/[category-id]/page.tsx`。
- 変更: `location-facts`の編集リンクの配置と基本情報の表示条件。
- 変更: 場所詳細・一覧のページテスト、視覚契約テスト、車いす状態の単体テスト、アクセシビリティのソース契約テスト。
- 変更: `docs/how-to/update-location-data.md`。
- 変更しない: 場所artifactの形式、OSM・WheelMapのURL、営業時間の評価、電話・ウェブサイト・Wikipediaの解決、API。
