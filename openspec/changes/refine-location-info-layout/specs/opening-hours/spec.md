# Spec Delta

## MODIFIED Requirements

### Requirement: 先一週間の予定

場所詳細は、今日から7日分の営業時間帯を表示しなければならない（MUST）。先頭の当日は日付と曜日の代わりに「今日」と表示し、残りの6日は日付と曜日を表示する（MUST）。営業時間がない日は「休み」と表示する（MUST）。1日に複数の時間帯がある場合は、すべて表示する（MUST）。

#### Scenario: 先頭を今日と表示する

- **WHEN** 一週間の営業時間を表示する
- **THEN** 先頭の当日は「今日」と表示され、2日目以降は日付と曜日が表示される

#### Scenario: 日別の時間帯を表示する

- **WHEN** 規則が`Mo-Fr 09:00-17:00; Sa-Su off`である
- **THEN** 平日は`09:00-17:00`、土日は「休み」と表示する

#### Scenario: 複数の時間帯を表示する

- **WHEN** 規則が`10:00-12:00,13:00-17:00`である
- **THEN** その日は2つの時間帯を表示する

### Requirement: 祝日の警告

規則に`PH`または`SH`がなく、営業状態を解釈できる場合、場所詳細は「祝日は通常と異なる場合があります。」を表示しなければならない（MUST）。規則に`PH`または`SH`がある場合、または営業状態を解釈できない場合は、この警告を表示しない（MUST NOT）。

#### Scenario: 祝日指定がない規則

- **WHEN** 規則が`Mo-Fr 09:00-17:00`である
- **THEN** 詳細は祝日の警告を表示する

#### Scenario: 祝日指定がある規則

- **WHEN** 規則が`Mo-Fr 09:00-17:00; PH off`である
- **THEN** 詳細は祝日の警告を表示しない

#### Scenario: 規則を解釈できない

- **WHEN** 規則を解釈できず、営業状態を表示できない
- **THEN** 詳細は祝日の警告を表示しない

## REMOVED Requirements

### Requirement: 営業時間の配置

**Reason**: 独立した営業時間セクションをなくし、基本情報の中で営業状態と営業時間の行に分けるため。

**Migration**: 「基本情報内の営業状態と営業時間」を使う。

## ADDED Requirements

### Requirement: 基本情報内の営業状態と営業時間

場所詳細の営業時間は、基本情報の中で「営業状態」と「営業時間」の2行に分けて表示しなければならない（MUST）。営業状態の行は状態バッジと、分かるときは次に変わる時刻、祝日の警告、目安の注意書きを持つ（MUST）。営業時間の行は一週間の一覧または生の規則と、目安の注意書きを持つ（MUST）。営業状態の行がないときは、営業時間の行に規則と目安の注意書きだけを表示し、祝日の警告を表示しない（MUST NOT）。基本情報の外に独立した営業時間セクションを置いてはならない（MUST NOT）。

#### Scenario: 基本情報の中で2行に分ける

- **WHEN** 場所詳細を表示する
- **THEN** 基本情報の中に「営業状態」と「営業時間」の行があり、営業状態の行には状態バッジ、次に変わる時刻、祝日の警告、目安の注意書き、営業時間の行には一週間の一覧と目安の注意書きがある

#### Scenario: 注意書きを両方の行に表示する

- **WHEN** 営業状態と営業時間を表示する
- **THEN** 「目安なので、正確な時間は施設に問い合わせてください。」が営業状態の行と営業時間の行の両方にある

#### Scenario: 独立した営業時間セクションを置かない

- **WHEN** 場所詳細を表示する
- **THEN** 基本情報の外に「営業時間」の見出しを持つセクションがない

#### Scenario: 規則がない

- **WHEN** 場所に`opening_hours`がない
- **THEN** 基本情報に営業状態と営業時間の行を表示しない

#### Scenario: 規則を解釈できない

- **WHEN** `opening_hours`の構文を解釈できない
- **THEN** 営業状態の行を表示せず、営業時間の行に規則と目安の注意書きだけを表示し、祝日の警告を表示しない
