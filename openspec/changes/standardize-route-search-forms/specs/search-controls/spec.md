# Spec Delta

## Purpose

サイト内で検索を実行するボタンの見た目とアクセシブルな名前を統一する。虫眼鏡アイコンのみの表示でも操作の目的を読み上げで識別でき、標準のフォーム送信とキーボード操作を利用できるようにする。

## ADDED Requirements

### Requirement: 検索ボタンの見た目と名前

サイト内で検索を実行するボタンは虫眼鏡アイコンのみを表示し、`aria-label="検索"`をアクセシブルな名前として持たなければならない（SHALL）。虫眼鏡アイコン自体は`aria-hidden="true"`とする。検索画面への移動リンクや、GPS取得・再編集など検索以外の操作はこの統一対象に含めない。

#### Scenario: 住所検索ボタンを表示する
- **WHEN** 目的地または出発地の住所検索ボタンを表示する
- **THEN** 見た目は虫眼鏡アイコンのみで、アクセシブルな名前は「検索」である
- **THEN** 所属するfieldsetのlegendと入力ラベルから検索対象を識別できる

#### Scenario: 最終検索ボタンを表示する
- **WHEN** 経路条件を送信する最終検索ボタンを表示する
- **THEN** 住所検索と同じ虫眼鏡アイコンのみの見た目と「検索」という名前を使う

### Requirement: 検索フォームの送信対象と操作性

検索ボタンは対応するフォームのsubmitボタンとして動作し、キーボードでも操作できなければならない（SHALL）。住所検索で最終経路検索を開始したり、ほかの必須項目の未入力によって住所検索を妨げたりしてはならない。ボタンは44 CSS px以上の幅と高さを持ち、可視フォーカスを提供する。

#### Scenario: 住所検索を先に実行する
- **WHEN** ほかの条件が未入力の状態で、住所検索フォームを送信する
- **THEN** 対象地点の住所だけを検索し、最終経路検索は開始しない
- **THEN** ほかのフォームの必須項目は住所検索を妨げない

#### Scenario: キーボードで検索する
- **WHEN** キーボードで検索ボタンへフォーカスして実行する
- **THEN** フォーカス位置を視認でき、対応するフォームだけが送信される
- **THEN** アイコンのみのボタンでも44 CSS px以上の操作領域を持つ
