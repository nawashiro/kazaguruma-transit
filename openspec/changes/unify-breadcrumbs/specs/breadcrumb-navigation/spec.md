# Spec Delta

## Purpose

サイト内のどの階層のページでも、同じ場所・同じ見た目で親階層へ戻れる、サイト共通のパンくずナビゲーションを提供する。

## ADDED Requirements

### Requirement: パンくずの共通配置

ページヘッダーはパンくずを受け取り、h1より上に表示しなければならない（SHALL）。パンくずはDaisyUIのbreadcrumbsコンポーネントの構造（nav要素とその中のul、li）を用い、nav要素にパンくずリストであることを示すラベルを付けなければならない（MUST）。パンくずが与えられないとき、ページヘッダーはパンくずを表示してはならない（MUST NOT）。ルビ以外のパンくずの文字は算出サイズ16px以上とし、テーマは既存のサイト全体と統一する。

#### Scenario: パンくずをh1より上に表示する
- **WHEN** パンくずを持つページを開く
- **THEN** nav要素のパンくずがh1より上に表示される
- **THEN** パンくずの文字サイズは16px以上で、ライト・ダークの両テーマで読める

#### Scenario: パンくずを持たないページを開く
- **WHEN** 親階層を持たないページ（トップ、各一覧、設定、使い方など）を開く
- **THEN** パンくずは表示されない

### Requirement: 親階層の列挙と現在位置

パンくずは現在ページからトップに向かう親階層を列挙しなければならない（SHALL）。各段は親ページへのリンクを表示し、最終段は現在ページの名前を`aria-current="page"`で示さなければならない（MUST）。場所詳細ページのパンくずは、カテゴリが分かるときは「場所一覧 > カテゴリ > 場所名」、分からないときは「場所一覧 > 場所名」とする。

#### Scenario: 場所詳細で親階層を辿る
- **WHEN** カテゴリが判明している場所詳細ページを開く
- **THEN** 「場所一覧 > カテゴリ > 場所名」の順に表示される
- **THEN** 場所一覧とカテゴリの各リンクから該当ページへ移動できる

#### Scenario: 現在位置を読み上げる
- **WHEN** 支援技術でパンくずを読み上げる
- **THEN** 最終段が現在ページであることが分かり、親階層のリンクと区別される

### Requirement: 対象外の画面要素

パンくずはページのナビゲーションとしてのみ使い、その場の操作として機能する要素を置き換えてはならない（MUST NOT）。エラー状態や完了カードの中で操作対象を示すボタン、戻り先がクエリパラメーターで動的に決まるリンクは、パンくずへ置き換えず現状の実装を維持する。

#### Scenario: エラー状態のボタンを維持する
- **WHEN** 会話編集や会話承認のページで、会話が見つからない旨のエラー表示を出す
- **THEN** 表示の中の戻るボタンはボタンのまま残り、パンくずへ置き換わらない

#### Scenario: 発生元への動的なリンクを維持する
- **WHEN** 利用制限ページを開く
- **THEN** 発生元の画面へ戻るリンクはリンクのまま表示され、パンくずへ置き換わらない
