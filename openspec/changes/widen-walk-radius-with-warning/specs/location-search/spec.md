# Spec Delta

## MODIFIED Requirements

### Requirement: 外部サービスに依存しない地点検索

地点検索と住所の逆引きは、サーバー内に保持した索引と徒歩ネットワークだけで行わなければならない（MUST）。Google Maps Geocoding APIを含む外部のジオコーディングサービスへ、検索・逆引きのための要求を送ってはならない（MUST NOT）。

#### Scenario: 名前で検索する

- **WHEN** 利用者が地名または施設名を入力して検索する
- **THEN** サーバーは外部へ要求を送らず、保持している索引から候補を返す

#### Scenario: 逆引きする

- **WHEN** 端末のGPSから座標を取得し、その座標の住所を求める
- **THEN** サーバーは外部へ要求を送らず、保持している索引から住所を返す

### Requirement: 候補の表示内容

各候補は、地点の名前と、その地点の住所を併せて識別できなければならない（MUST）。住所を解決できない候補は、緯度と経度を代わりに示す（MUST）。各候補は、最寄り停留所までの徒歩距離も持つ（MUST）。

#### Scenario: 名前と住所を表示する

- **WHEN** 候補を表示する
- **THEN** `名前 住所`の形で地点を識別できる

#### Scenario: 住所を解決できない

- **WHEN** 候補の座標から住所を解決できない
- **THEN** 緯度と経度を表示する

#### Scenario: 候補の徒歩距離を示す

- **WHEN** 候補の最寄り停留所までの徒歩距離が537mである
- **THEN** 候補は名前と住所に加えて徒歩距離を持つ

### Requirement: 索引の鮮度と失敗時の挙動

索引はリポジトリに置いた生成物から読み、ビルドや起動のたびに外部から取り直してはならない（MUST NOT）。索引を読み込めない、または形式が不正なときは、検索を行わずに失敗を返し、外部サービスへ代替要求を送ってはならない（MUST NOT）。索引の更新は、内容が変わったときだけファイルを書き換える（MUST）。

#### Scenario: 索引を更新する

- **WHEN** 作業者が索引の更新コマンドを実行し、索引の内容が前回と異なる
- **THEN** 索引ファイルが新しい内容で書き換わり、ビルドはそのファイルを読むだけである

#### Scenario: 内容が変わっていない索引を更新する

- **WHEN** 作業者が索引の更新コマンドを実行し、索引の内容が前回と同じである
- **THEN** 索引ファイルを書き換えず、生成日時だけを理由に差分を出さない
- **THEN** コマンドは書き換えなかったことを報告する

#### Scenario: 索引が壊れている

- **WHEN** 索引ファイルが存在しない、または形式が不正である
- **THEN** 検索は失敗を返し、外部のジオコーディングサービスへ問い合わせない

## ADDED Requirements

### Requirement: 検索候補の最寄り停留所までの徒歩距離

地点検索の応答は、各候補の最寄り停留所までの徒歩距離をメートルの整数で返さなければならない（MUST）。距離は経路検索の停留所選択と同じ徒歩ネットワークで測る（MUST）。徒歩距離を求められない候補は、距離を持たない（MUST）。距離は`/api/geocode`の検索と逆引きの両方の応答に含める（MUST）。

#### Scenario: 検索候補に徒歩距離を付ける

- **WHEN** 利用者が`科学技術館`を検索する
- **THEN** 応答の候補は`walkMeters`を持ち、その値は経路検索の停留所選択と同じ徒歩ネットワークから測った最寄り停留所までの距離と一致する

#### Scenario: 徒歩距離を求められない候補

- **WHEN** 候補の座標が徒歩ネットワークへ接続できない
- **THEN** 応答の候補は`walkMeters`を持たず、ほかの項目は返す

#### Scenario: 逆引きに徒歩距離を付ける

- **WHEN** 端末のGPSの座標を逆引きし、最寄り停留所まで720mである
- **THEN** 逆引きの応答は`walkMeters: 720`を持つ

#### Scenario: 徒歩距離の算出に失敗する

- **WHEN** 徒歩ネットワークを読み込めない
- **THEN** 検索と逆引きは候補と住所を返し続け、`walkMeters`を付けない
- **THEN** 検索は失敗を返さない
