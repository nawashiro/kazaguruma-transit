# Spec Delta

## MODIFIED Requirements

### Requirement: 入力中の候補表示

住所・場所名の入力中に、サーバーへ問い合わせた候補を入力欄の直下へ自動で表示しなければならない（SHALL）。候補の表示に決定ボタンの押下を要求してはならない（MUST NOT）。候補は、地点の名前と住所を併せて識別できる形で示す。候補は、最寄り停留所までの徒歩距離に応じた警告を示す（SHALL）。警告は文字を含むバッジとし、距離の数値を併記しない（SHALL）。

#### Scenario: 打鍵で候補が出る

- **WHEN** 利用者が目的地または出発地の入力欄に2文字以上を入力する
- **THEN** 入力欄を離れずに、その語に一致する候補が入力欄の直下に表示される
- **THEN** 各候補から名前と住所を読み取れる

#### Scenario: 変換中の文字では検索しない

- **WHEN** 日本語入力の変換が確定していない状態で文字が入力される
- **THEN** 変換が確定するまでサーバーへ問い合わせず、未確定の読みで候補を表示しない

#### Scenario: 入力を消す

- **WHEN** 利用者が入力欄の文字をすべて消す
- **THEN** 候補を表示せず、サーバーへ問い合わせない

### Requirement: 候補項目の操作可能性の提示

候補一覧の各項目は、ポインターを重ねると背景色が変わり、ポインターの形が指になる（MUST）。背景色の変化は入力グループの地色に対して見て分かる差を持つ（MUST）。キーボードのフォーカス表示は従来どおり保つ（MUST）。選択できない候補も同じ見た目の手掛かりを持ち、ポインターの形だけを変えない（MUST）。

#### Scenario: 候補にポインターを重ねる

- **WHEN** 候補一覧の項目にポインターを重ねる
- **THEN** 項目の背景色が入力グループの地色から変わり、ポインターの形が指になる
- **THEN** 項目の文字と名前・住所は読み取れるままである

#### Scenario: キーボードで候補へ移動する

- **WHEN** キーボードで候補一覧の項目へ移動する
- **THEN** 可視フォーカスが表示される

#### Scenario: 遠すぎる候補にポインターを重ねる

- **WHEN** 750mを超える候補にポインターを重ねる
- **THEN** ポインターの形は変えず、項目は選べないことを文字と図形で示したままである

### Requirement: 施設カテゴリの折りたたみ一覧

施設カテゴリは標準のdetailsとsummaryで縦に並べ、施設をリストで提供しなければならない（SHALL）。施設名を省略せず折り返し、箇条書きの代わりのピンアイコンを置かない。カテゴリと施設一覧に固定の高さ制限や内部スクロールを設けず、ページ全体でスクロールできるようにする。施設の各項目は、500mを超えるときは「バス停から遠い」の警告を文字で示す（SHALL）。警告は距離の数値を併記しない。目録の候補は750m以内に限られるため、施設一覧から選べない項目は生じない（MUST NOT）。

#### Scenario: カテゴリを開いて施設を選ぶ
- **WHEN** 利用者がキーボードでカテゴリを開き、施設を選ぶ
- **THEN** 施設が目的地として確定し、ほかの入力グループは表示されたままである

#### Scenario: 長い名前を狭い画面で読む
- **WHEN** 320 CSS px相当の表示幅で長いカテゴリ名と施設名を表示する
- **THEN** 名前を全文読め、一覧内またはページの横スクロールを必要としない

#### Scenario: 遠い施設を一覧から選ぶ
- **WHEN** カテゴリの一覧に、最寄り停留所まで535mの施設がある
- **THEN** その施設の項目に「バス停から遠い」の警告が表示される
- **THEN** その施設を目的地として確定できる

## ADDED Requirements

### Requirement: 徒歩距離に応じた地点の警告

出発地と目的地の候補は、最寄り停留所までの徒歩距離が500mを超えるとき「バス停から遠い」と示さなければならない（MUST）。徒歩距離が750mを超えるとき「バス停から遠すぎ」と示さなければならない（MUST）。警告は色だけで伝えず、文字を含む（MUST NOT）。徒歩距離を持たない候補は、警告を出さずに選択できるままにする。

#### Scenario: 遠い候補

- **WHEN** 検索候補の最寄り停留所までの徒歩距離が537mである
- **THEN** その候補は「バス停から遠い」の文字を含む警告を表示する
- **THEN** その候補に距離の数値は表示しない

#### Scenario: 遠すぎる候補

- **WHEN** 検索候補の最寄り停留所までの徒歩距離が939mである
- **THEN** その候補は「バス停から遠すぎ」と表示する

#### Scenario: 徒歩距離のない候補

- **WHEN** 候補が徒歩距離を持たない
- **THEN** 警告を表示せず、その候補を地点として確定できる

### Requirement: 徒歩距離の段階を示す図形

各候補は、徒歩距離の段階を図形でも示さなければならない（MUST）。色を見分けられなくても段階を読み分けられるよう、図形そのものを変える。通常は丸、500mを超え750m以内は三角、750mを超えるとバツとする。図形は装飾であり、読み上げの対象にしない（MUST NOT）。

#### Scenario: 段階ごとの図形

- **WHEN** 徒歩距離が450m、537m、939mの候補を並べる
- **THEN** 図形はそれぞれ丸、三角、バツになる
- **THEN** 図形は`aria-hidden`で読み上げの対象にならない

#### Scenario: 徒歩距離を持たない候補

- **WHEN** 候補が徒歩距離を持たない
- **THEN** 図形は丸になる

### Requirement: 選べない候補の提示と確定の禁止

750mを超える候補は、地点として確定できなくしなければならない（MUST）。選択できない候補は、`disabled`属性ではなく`aria-disabled="true"`を付けた`button`として残す（MUST）。フォーカスと読み上げの対象に残し、選べない理由を`aria-describedby`で説明文として読ませる（MUST）。押下やEnterでは地点を確定しない（MUST）。理由の説明文は、同じ内容を可視のバッジと重複して読ませない（MUST NOT）。地色を変え、枠を破線にして、見た目でも選べないことを示す（MUST）。候補は一覧から消さず、名前と住所を読み取れる形で残す（MUST）。

#### Scenario: 遠すぎる候補を押す

- **WHEN** 徒歩距離が939mの候補を押す、またはEnterを押す
- **THEN** 地点は確定しない
- **THEN** その候補の項目は地色が変わり、枠が破線になる
- **THEN** その候補の名前と住所を読み取れる

#### Scenario: 遠すぎる候補をキーボードでたどる

- **WHEN** キーボードで候補一覧をたどる
- **THEN** 選択できない候補にもフォーカスが当たり、可視フォーカスが表示される
- **THEN** その候補は「利用不可」と読まれ、続けて選べない理由が読まれる
- **THEN** EnterやSpaceを押しても地点は確定しない

#### Scenario: 遠すぎる候補を読み上げる

- **WHEN** 読み上げソフトで939mの候補にフォーカスを移す
- **THEN** 名前と住所、「バス停から遠すぎ」の状態、選べない理由が順に読まれる
- **THEN** 同じ理由をバッジと説明文で二重に読まない

### Requirement: 出発地と目的地への同じ適用

警告と選択の制限は、目的地と出発地の両方に同じ基準で適用しなければならない（MUST）。出発地がバス停から750mを超える地点であるときも、同じ警告と選択の制限を示す（MUST）。

#### Scenario: 出発地がバス停から遠い

- **WHEN** 出発地の候補の最寄り停留所までの徒歩距離が537mである
- **THEN** 出発地の候補に「バス停から遠い」の警告を表示する

#### Scenario: 出発地がバス停から遠すぎる

- **WHEN** 出発地の候補の最寄り停留所までの徒歩距離が939mである
- **THEN** 出発地の候補は地点として確定できない

### Requirement: 施設詳細から渡された目的地の遠さ

入力画面は、URLで渡された目的地の徒歩距離に応じた警告を確定済みの表示に示さなければならない（MUST）。施設詳細から渡された目的地がバス停から750mを超えるときは、確定済みの表示に「バス停から遠すぎ」と示す（MUST）。確定済みの表示に距離の数値は出さない（SHALL）。その状態で最終検索を行うと、結果画面が地点と徒歩距離を示す（MUST）。

#### Scenario: 遠い目的地を渡される

- **WHEN** 施設詳細から最寄り停留所まで963mの地点を目的地として入力画面を開く
- **THEN** 確定済みの目的地に「バス停から遠すぎ」が表示される
- **THEN** 最終検索の結果は、その地点と徒歩距離を示す

#### Scenario: 遠い目的地を渡されない

- **WHEN** 施設詳細から最寄り停留所まで537mの地点を目的地として入力画面を開く
- **THEN** 確定済みの目的地に「バス停から遠い」が表示される
- **THEN** 最終検索を行うと経路を検索する
