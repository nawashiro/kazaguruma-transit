# Spec Delta

## MODIFIED Requirements

### Requirement: 検索失敗と利用制限

結果ページは条件不正、経路なし、検索処理の失敗を識別できる表示を提供しなければならない（SHALL）。サーバー描画経由でも既存の利用制限を適用し、上限到達時は`/rate-limit?source=routes`へ案内する。検索経路を変えることで利用制限を迂回したり、1回の検索を二重計上したりしてはならない。エラー表示の際もパンくずから入力画面へ戻れる。出発地または目的地の最寄り停留所までの徒歩距離が上限を超えるときは、経路なしと区別し、どちらの地点が何メートルかを示す（MUST）。

#### Scenario: 条件が不正である
- **WHEN** 必須パラメーターが不足、または座標・日時・真偽値が不正である
- **THEN** 条件不正を日本語で表示し、経路計算は実行しない
- **THEN** h1より上のパンくずから入力画面へ戻れる

#### Scenario: 経路がない
- **WHEN** 検索処理は成功したが該当経路がない
- **THEN** 経路がない旨をHTMLで表示し、パンくずから入力画面へ戻れる

#### Scenario: 目的地がバス停から遠すぎる
- **WHEN** 目的地の最寄り停留所までの徒歩距離が939mである
- **THEN** 結果ページは経路がない旨ではなく、目的地がバス停から939mであることを表示する
- **THEN** パンくずから入力画面へ戻れる

#### Scenario: 出発地がバス停から遠すぎる
- **WHEN** 出発地の最寄り停留所までの徒歩距離が963mである
- **THEN** 結果ページは出発地がバス停から963mであることを表示する

#### Scenario: 検索処理が失敗する
- **WHEN** サーバーの経路取得に失敗する
- **THEN** 日本語のエラーを表示し、パンくずから入力画面へ戻れる

#### Scenario: 利用制限に達する
- **WHEN** 同じ利用者の検索が既存の利用上限に達する
- **THEN** サーバー描画の結果ページでも利用制限画面へ案内する
- **THEN** 経路APIを直接使った場合と同じ制限を受ける

## ADDED Requirements

### Requirement: 徒歩区間の距離と警告

結果ページは、出発地から乗車停留所までと、降車停留所から目的地までの徒歩距離をメートルで表示しなければならない（MUST）。表示位置は「徒歩で移動(Googleマップ)」のリンクの直下とする（MUST）。徒歩距離が500mを超える徒歩区間には「バス停から遠い」の警告を付ける（MUST）。警告は色だけで伝えず、文字を含む（MUST NOT）。徒歩距離を求められない区間は、距離も警告も表示しない（MUST NOT）。

#### Scenario: 遠い徒歩区間を表示する

- **WHEN** 出発地から乗車停留所までの徒歩距離が537mである
- **THEN** 「徒歩で移動(Googleマップ)」の直下に`(バス停から遠い) 537m`を表示する

#### Scenario: 近い徒歩区間を表示する

- **WHEN** 目的地までの徒歩距離が120mである
- **THEN** 「徒歩で移動(Googleマップ)」の直下に`120m`を表示し、警告を付けない

#### Scenario: 徒歩区間がない

- **WHEN** 乗車停留所が入力画面の地点と同じ座標である
- **THEN** 徒歩区間の距離を表示せず、警告も付けない
