# Spec Delta

## MODIFIED Requirements

### Requirement: バス停候補の徒歩距離上限

周辺バス停の絞り込みは、徒歩ネットワーク上の徒歩距離で行わなければならない（MUST）。徒歩距離の上限は `TRANSIT_PARAMS.MAX_WALK_TO_STOP_METERS`（750メートル）とする。警告を出す距離は `TRANSIT_PARAMS.WARN_WALK_TO_STOP_METERS`（500メートル）とし、上限とは別の値として持つ（MUST）。上限ちょうどの徒歩距離は候補として採用する。直線距離に碁盤目街路の最悪補正係数√2を掛けた値を徒歩距離として使ってはならない（MUST NOT）。

#### Scenario: 徒歩距離が上限以内のバス停
- **WHEN** 出発地からバス停までの徒歩距離が745メートルである
- **THEN** そのバス停は候補として採用する

#### Scenario: 徒歩距離が上限を超えるバス停
- **WHEN** 出発地からバス停までの徒歩距離が759メートルである
- **THEN** そのバス停は候補から除外する

#### Scenario: 上限定義ちょうどのバス停
- **WHEN** 出発地からバス停までの徒歩距離が750メートルである
- **THEN** そのバス停は候補として採用する

#### Scenario: 警告線を超え上限以内のバス停
- **WHEN** 出発地からバス停までの徒歩距離が537メートルである
- **THEN** そのバス停は候補として採用し、500メートルを超えたことを呼び出し側へ示す

#### Scenario: 直線距離は短いが徒歩距離が長いバス停
- **WHEN** 出発地からバス停までの直線距離は350メートルだが、川を渡る橋が遠く徒歩距離が770メートルである
- **THEN** そのバス停は候補から除外する

#### Scenario: 直線距離は長いが徒歩距離が短いバス停
- **WHEN** 出発地からバス停までの直線距離は600メートルだが、直通の歩道があり徒歩距離が640メートルである
- **THEN** そのバス停は候補として採用する

### Requirement: 全ての検索経路での徒歩距離上限の適用

従来経路（最寄りバス停1件）も同じ上限に従わなければならない（MUST）。出発地または目的地のいずれかで、最寄りバス停の徒歩距離が上限を超える場合、従来経路は経路なしとして返す。周辺バス停経路も同じ上限を使う（MUST）。

#### Scenario: 最寄りバス停が上限を超える
- **WHEN** 出発地の最寄りバス停の徒歩距離が750メートルを超える
- **THEN** 従来経路は経路を返さない
- **THEN** 検索は既存の周辺バス停経路にフォールバックする

#### Scenario: 目的地の最寄りバス停が上限を超える
- **WHEN** 目的地の最寄りバス停の徒歩距離が750メートルを超える
- **THEN** 周辺バス停経路も経路を返さない

#### Scenario: 最寄りバス停が上限以内である
- **WHEN** 出発地と目的地の最寄りバス停の徒歩距離がどちらも750メートル以内である
- **THEN** 既存の従来経路の検索をそのまま実行する
