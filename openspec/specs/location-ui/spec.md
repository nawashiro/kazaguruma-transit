# location-ui Specification

## Purpose
場所一覧と場所詳細の外観をDaisyUIの標準構造に揃え、状態・操作・出典・写真帰属を読み手が誤解なく理解できるようにする。

## Requirements

### Requirement: 車いす情報とバリアフリー情報の分割

場所詳細は、車いすの状態を示す「車いす情報」と、外部リンクを示す「バリアフリー情報」を別のセクションに分けなければならない（MUST）。車いす情報は状態バッジ・説明文・参照リンクを持ち、バリアフリー情報は言葉の道案内や東京バリアフリーマップなどの外部リンクだけを持つ（MUST）。外部リンクがないときはバリアフリー情報の見出しを表示しない（MUST NOT）。

#### Scenario: 2つのセクションに分ける

- **WHEN** 場所詳細を表示する
- **THEN** 「車いす情報」には状態バッジがあり、「バリアフリー情報」には外部リンクだけがあり、状態バッジを持たない

#### Scenario: 外部リンクがない

- **WHEN** 関連する外部リンクがない場所の詳細を表示する
- **THEN** 「バリアフリー情報」の見出しを表示しない

#### Scenario: 車いすの状態を隠さない

- **WHEN** 外部リンクがない場所の詳細を表示する
- **THEN** 「車いす情報」は状態バッジと説明文を表示する

### Requirement: 状態バッジの意味色

場所一覧と場所詳細の状態バッジは、アウトラインではなく意味色で塗り分けなければならない（MUST）。全面は成功色、一部は警告色、非対応はエラー色、情報なしは無彩色とし、状態文言を必ず含める（MUST）。営業状態は、営業中と24時間営業を成功色、営業時間外をエラー色で示す（MUST）。

#### Scenario: 一覧の状態を塗り分ける

- **WHEN** 一覧に全面・一部・非対応の場所を表示する
- **THEN** それぞれ成功色・警告色・エラー色の塗りバッジに状態文言が入る

#### Scenario: 営業状態を塗り分ける

- **WHEN** 場所詳細に営業中または営業時間外を表示する
- **THEN** 成功色またはエラー色の塗りバッジにその文言が入る

#### Scenario: 情報なしを区別する

- **WHEN** 一覧または場所詳細で状態が情報なしである
- **THEN** 無彩色のバッジに「情報なし」が入る

### Requirement: 状態バッジと説明の横並び

場所詳細の車いす情報は、状態バッジと説明文を同じ行に並べなければならない（MUST）。狭い画面で折り返す場合も、状態バッジの文言を分割してはならない（MUST NOT）。

#### Scenario: 状態と説明を横に並べる

- **WHEN** 状態が「全面」である
- **THEN** 「全面」のバッジと「入口には段がなく、全部の部屋に段がありません。」が同じ行に並ぶ

#### Scenario: 情報なしの案内を横に並べる

- **WHEN** 状態が「情報なし」である
- **THEN** 「情報なし」のバッジと説明文が同じ行に並ぶ

### Requirement: ルビ表示とバッジの干渉防止

状態バッジと操作ボタンは、ルビ表示の対象外にしなければならない（MUST）。ルビ表示を有効にしても、バッジの文言を折り返さず、ボタンのラベルを上下にずらしてはならない（MUST NOT）。営業時間の一覧の日付・曜日・時間帯にもルビを付けない（MUST NOT）。文章にはこれまでどおりルビを適用する（MUST）。

#### Scenario: バッジの文言を折り返さない

- **WHEN** ルビ表示を有効にして「営業時間外」または「一部」のバッジを表示する
- **THEN** バッジの文言は1行のままで、ルビの注釈によって分割されない

#### Scenario: ボタンのラベルを中央に保つ

- **WHEN** ルビ表示を有効にして車いす情報の参照リンクを表示する
- **THEN** ボタンのラベルは上下の中央に置かれ、上端に寄らない

#### Scenario: 営業時間の一覧にルビを付けない

- **WHEN** ルビ表示を有効にして営業時間の一覧を表示する
- **THEN** 日付・曜日・時間帯にはルビが付かない

#### Scenario: 文章のルビを残す

- **WHEN** ルビ表示を有効にして車いす情報の説明文を表示する
- **THEN** 説明文にはルビが付く

### Requirement: 場所詳細の操作ボタン

場所詳細の編集リンクと車いす情報の参照リンクは、セカンダリの塗りボタンとして表示しなければならない（MUST）。アウトラインのボタンを使ってはならない（MUST NOT）。角丸は同じ画面の主要ボタンと揃え、高さは44 CSS px以上、文字は16px以上とする（MUST）。ボタンのラベルは標準の中央揃えで表示し、上端に寄せてはならない（MUST NOT）。

#### Scenario: 編集リンクの形

- **WHEN** 編集リンクを表示する
- **THEN** セカンダリの塗りボタンになり、角丸が「ここへ行く」と同じになる

#### Scenario: 参照リンクの形

- **WHEN** 車いす情報の参照リンクを表示する
- **THEN** セカンダリの塗りボタンになる

#### Scenario: 操作領域を保つ

- **WHEN** 編集リンクまたは参照リンクを表示する
- **THEN** 高さは44 CSS px以上、文字は16px以上になる

#### Scenario: ラベルを中央に置く

- **WHEN** 編集リンクまたは参照リンクを表示する
- **THEN** ラベルはボタンの中央に置かれ、上端に寄らない

### Requirement: 基本情報の行揃え

基本情報はdtとddを同じ行に置かなければならない（MUST）。1行で収まる値では文字の中心を揃え、複数行になる値では上端を揃える（MUST）。dtとddの文字サイズは16px以上で同じにし、リンクの操作領域は44 CSS px以上とする（MUST）。

#### Scenario: 行の中心を揃える

- **WHEN** 電話・ウェブサイト・Wikipediaを表示する
- **THEN** 各行のdtとddの文字の中心が同じ高さになる

#### Scenario: 複数行の値は上端を揃える

- **WHEN** 基本情報の中に一週間の営業時間を表示する
- **THEN** 営業時間のdtとddは上端で揃う

#### Scenario: 文字サイズを揃える

- **WHEN** 基本情報を表示する
- **THEN** dtとddの文字は16px以上で同じ大きさになる

#### Scenario: 操作領域を保つ

- **WHEN** 基本情報のリンクを操作する
- **THEN** リンクは44 CSS px以上の高さを持つ

### Requirement: 一覧カードの構造と写真帰属

場所一覧のカードは、画像を最初の子に置き、本文をカード本文に置く標準構造にしなければならない（MUST）。画像の角は上端だけをカードの角丸に合わせ、下端は丸めてはならない（MUST NOT）。写真の帰属はカード本文の中に「写真 作者・ライセンス」の1行で示す（MUST）。作者が分からないときは「写真 作者不明・ライセンス」と示す（MUST）。コロンやスラッシュで連結してはならず、ライセンスをリンクにしてはならない（MUST NOT）。

#### Scenario: 帰属をカード本文に置く

- **WHEN** 画像付きの場所カードを表示する
- **THEN** 作者とライセンスはカード本文にあり、場所名・地域と同じ左端に並ぶ

#### Scenario: 帰属を1行で示す

- **WHEN** 写真の作者とライセンスを表示する
- **THEN** 「写真」、作者、ライセンスが「・」で区切られた1行になり、「ライセンス」の別ラベルを付けない

#### Scenario: 作者がない画像の帰属を示す

- **WHEN** 作者のない写真を持つ場所カードを表示する
- **THEN** 「写真 作者不明・ライセンス」の1行が表示される

#### Scenario: ライセンスのリンクを詳細へ委ねる

- **WHEN** 一覧カードのライセンスを表示する
- **THEN** カード内のライセンスはリンクではなく、詳細ページだけがリンクを持つ

#### Scenario: 画像の角を上端だけ丸める

- **WHEN** 画像付きの場所カードを表示する
- **THEN** 画像の上端だけがカードの角丸に沿って丸く、下端は角が立つ

### Requirement: 場所写真のレスポンシブ表示

場所一覧と場所詳細の写真は、ビルドで生成した派生画像を `srcset` と `sizes` で選んで表示しなければならない（MUST）。一覧カードは遅延読み込み、詳細の先頭写真は即時読み込みにし（MUST）、読み込み前に表示領域を確保するため `width` と `height` を持つ（MUST）。写真は装飾として `alt=""` を持つ（MUST）。帰属の表示は従来どおりとする（MUST）。

#### Scenario: 一覧カードで幅を選ぶ

- **WHEN** 一覧カードに写真を表示する
- **THEN** `srcset` には生成済みの派生画像が幅の小さい順に入り、`loading` は `lazy` である

#### Scenario: 詳細の先頭写真を優先して読み込む

- **WHEN** 場所詳細の先頭写真を表示する
- **THEN** `srcset` は1280pxまでを含み、`loading` は `eager`、`fetchpriority` は `high` である

#### Scenario: 読み込み前に領域を確保する

- **WHEN** 写真を読み込む
- **THEN** `width` と `height` があり、読み込みでレイアウトが動かない

#### Scenario: 写真を装飾として扱う

- **WHEN** 写真を表示する
- **THEN** `alt` は空である

### Requirement: データの出典表示

場所詳細は、車いす情報と基本情報の操作ボタンの後に、「© OpenStreetMap contributors ODbL-1.0」の出典を表示しなければならない（MUST）。独立した提供元セクションを表示してはならない（MUST NOT）。

#### Scenario: 車いす情報の直後に出典を置く

- **WHEN** 車いす情報を表示する
- **THEN** 状態・説明・参照リンクの後に「© OpenStreetMap contributors ODbL-1.0」が表示される

#### Scenario: 基本情報の直後に出典を置く

- **WHEN** 基本情報を表示する
- **THEN** 情報の行と編集リンクの後に「© OpenStreetMap contributors ODbL-1.0」が表示される

#### Scenario: 提供元セクションを置かない

- **WHEN** 場所詳細を表示する
- **THEN** 「提供」の見出しを持つ独立したセクションがない

#### Scenario: 画像の帰属と混ぜない

- **WHEN** 画像付きの場所詳細を表示する
- **THEN** 画像の作者とライセンスは画像の直後に残り、OpenStreetMapの出典行と混ざらない

### Requirement: 標準コンポーネントの利用

場所一覧と場所詳細の状態表示・操作・カード・情報行は、DaisyUIの標準コンポーネントで表示しなければならない（MUST）。カード状の独自ブロックや独自の状態表示を追加してはならない（MUST NOT）。

#### Scenario: 状態を標準バッジで示す

- **WHEN** 場所の状態または営業状態を表示する
- **THEN** 標準のバッジで表示する

#### Scenario: カードを標準構造で示す

- **WHEN** 場所カードを表示する
- **THEN** 標準のカード構造で表示する

#### Scenario: 独自のブロックを追加しない

- **WHEN** 車いす情報またはバリアフリー情報を表示する
- **THEN** 標準のセクションとバッジの外に、独自のカード状ブロックを追加しない
