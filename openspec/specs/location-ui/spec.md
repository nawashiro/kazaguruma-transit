# location-ui Specification

## Purpose
場所一覧と場所詳細の外観をDaisyUIの標準構造に揃え、状態・操作・出典・写真帰属を読み手が誤解なく理解できるようにする。

## Requirements

### Requirement: バリアフリー情報の構成

場所詳細のバリアフリー情報は、見出しの下に状態バッジ、説明文、参照リンクを置き、カード状の入れ子を作ってはならない（MUST NOT）。状態バッジは車いすのアイコンと状態文言を含み、アイコンには「車いす」の代替テキストを添えなければならない（MUST）。状態文言は「全面」「一部」「非対応」「情報なし」とし、セクション内に出典を表示してはならない（MUST NOT）。

#### Scenario: カードを入れ子にしない

- **WHEN** 場所詳細のバリアフリー情報を表示する
- **THEN** セクションの内側に独立したカードや色付きのカード状ブロックがない

#### Scenario: アイコンに代替テキストを添える

- **WHEN** 状態が「一部」のバッジを支援技術で読む
- **THEN** 「車いす」「一部」の順に読み上げる

#### Scenario: 出典を重複させない

- **WHEN** バリアフリー情報のセクションを表示する
- **THEN** 「情報源: OpenStreetMap」を表示しない

### Requirement: 状態バッジの意味色

場所一覧と場所詳細の状態バッジは、アウトラインではなく意味色で塗り分けなければならない（MUST）。全面は成功色、一部は警告色、非対応はエラー色、情報なしは無彩色とし、状態文言を必ず含める（MUST）。営業状態は、営業中と24時間営業を成功色、営業時間外をエラー色で示す（MUST）。

#### Scenario: 一覧の状態を塗り分ける

- **WHEN** 一覧に全面・一部・非対応の場所を表示する
- **THEN** それぞれ成功色・警告色・エラー色の塗りバッジに状態文言が入る

#### Scenario: 営業状態を塗り分ける

- **WHEN** 場所詳細に営業中または営業時間外を表示する
- **THEN** 成功色またはエラー色の塗りバッジにその文言が入る

#### Scenario: 情報なしを区別する

- **WHEN** 場所詳細の状態が情報なしである
- **THEN** 無彩色のバッジに「情報なし」が入り、一覧にはバッジを表示しない

### Requirement: 場所詳細の操作ボタン

場所詳細の編集リンクとバリアフリー情報の参照リンクは、セカンダリの塗りボタンとして表示しなければならない（MUST）。アウトラインのボタンを使ってはならない（MUST NOT）。角丸は同じ画面の主要ボタンと揃え、高さは44 CSS px以上、文字は16px以上とする（MUST）。

#### Scenario: 編集リンクの形

- **WHEN** 編集リンクを表示する
- **THEN** セカンダリの塗りボタンになり、角丸が「ここへ行く」と同じになる

#### Scenario: 参照リンクの形

- **WHEN** バリアフリー情報の参照リンクを表示する
- **THEN** セカンダリの塗りボタンになる

#### Scenario: 操作領域を保つ

- **WHEN** 編集リンクまたは参照リンクを表示する
- **THEN** 高さは44 CSS px以上、文字は16px以上になる

### Requirement: 基本情報の行揃え

基本情報はdtとddを同じ行に置き、行の中で文字の中心を揃えなければならない（MUST）。dtとddの文字サイズは16px以上で同じにし、リンクの操作領域は44 CSS px以上とする（MUST）。

#### Scenario: 行の中心を揃える

- **WHEN** 電話・ウェブサイト・Wikipediaを表示する
- **THEN** 各行のdtとddの文字の中心が同じ高さになる

#### Scenario: 文字サイズを揃える

- **WHEN** 基本情報を表示する
- **THEN** dtとddの文字は16px以上で同じ大きさになる

#### Scenario: 操作領域を保つ

- **WHEN** 基本情報のリンクを操作する
- **THEN** リンクは44 CSS px以上の高さを持つ

### Requirement: 一覧カードの写真帰属

場所一覧のカードは、画像を最初の子に置き、本文をカード本文に置く標準構造にしなければならない（MUST）。画像の角は上端だけをカードの角丸に合わせ、下端は丸めてはならない（MUST NOT）。写真の帰属はカード本文の中に置き、作者とライセンスをdtとddで示す（MUST）。コロンやスラッシュで連結してはならず、ライセンスをリンクにしてはならない（MUST NOT）。

#### Scenario: 帰属をカード本文に置く

- **WHEN** 画像付きの場所カードを表示する
- **THEN** 作者とライセンスはカード本文にあり、場所名・地域と同じ左端に並ぶ

#### Scenario: 区切りにdtとddを使う

- **WHEN** 写真の作者とライセンスを表示する
- **THEN** 「写真」と作者、「ライセンス」と名前をdtとddの組で示し、コロンを使わない

#### Scenario: ライセンスのリンクを詳細へ委ねる

- **WHEN** 一覧カードのライセンスを表示する
- **THEN** カード内のライセンスはリンクではなく、詳細ページだけがリンクを持つ

#### Scenario: 画像の角を上端だけ丸める

- **WHEN** 画像付きの場所カードを表示する
- **THEN** 画像の上端だけがカードの角丸に沿って丸く、下端は角が立つ

### Requirement: 提供元の単一表示

場所詳細の提供元は、OpenStreetMapの1件だけを表示しなければならない（MUST）。座標・電話などの項目列挙、バリアフリー情報の個別行、画像の個別行を表示してはならない（MUST NOT）。OpenStreetMap contributors（ODbL 1.0）をリンク付きで示し、施設情報とバリアフリー情報（wheelchairタグ）の出典であることを1文で添える（MUST）。

#### Scenario: 1件に集約する

- **WHEN** 提供元を表示する
- **THEN** OpenStreetMap contributorsへのリンクは1件だけになる

#### Scenario: 項目の列挙を出さない

- **WHEN** 提供元を表示する
- **THEN** 「座標・電話・ウェブサイト・営業時間」のような項目列挙を表示しない

#### Scenario: 画像の帰属を再掲しない

- **WHEN** 画像付きの場所の提供元を表示する
- **THEN** 画像の作者とライセンスを提供元に再掲しない

#### Scenario: 出典の範囲を示す

- **WHEN** 提供元を表示する
- **THEN** 施設情報とバリアフリー情報がOpenStreetMap由来だと分かる

### Requirement: 標準コンポーネントの利用

場所一覧と場所詳細の状態表示・操作・カード・情報行は、DaisyUIの標準コンポーネントで表示しなければならない（MUST）。カード状の独自ブロックや独自の状態表示を追加してはならない（MUST NOT）。

#### Scenario: 状態を標準バッジで示す

- **WHEN** 場所の状態または営業状態を表示する
- **THEN** 標準のバッジで表示する

#### Scenario: カードを標準構造で示す

- **WHEN** 場所カードを表示する
- **THEN** 標準のカード構造で表示する

#### Scenario: 独自のブロックを追加しない

- **WHEN** バリアフリー情報を表示する
- **THEN** 標準のセクションとバッジの外に、独自のカード状ブロックを追加しない
