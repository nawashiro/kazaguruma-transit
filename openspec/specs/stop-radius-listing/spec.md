# stop-radius-listing Specification

## Purpose
指定した座標と半径から、その直線距離内にあるバス停の一覧を近い順に提供し、あわせて最寄りバス停の選択を定める。半径一覧の距離は直線距離、最寄りバス停の選択は徒歩距離であり、両者は別の定義である。

## Requirements

### Requirement: 半径一覧は全てのバス停を評価する

半径内のバス停の一覧は、全てのバス停に対して距離を計算した結果を返さなければならない（MUST）。距離計算の前に取得するバス停の件数で返す一覧を限定してはならない。直線距離はハバーサインで計算する。返す一覧は近い順で、最大10件とする。半径一覧の直線距離は経路検索の徒歩距離とは別の定義であり、入れ替えてはならない（MUST NOT）。

#### Scenario: 取得順が後ろのバス停も半径内に現れる
- **WHEN** DBの取得順が11番目以降のバス停が、指定した座標から半径内にある
- **THEN** そのバス停は一覧に現れる

#### Scenario: 半径外のバス停は一覧から外れる
- **WHEN** バス停が指定した座標から半径より遠い
- **THEN** そのバス停は一覧に現れない

#### Scenario: 半径内が11件以上ある
- **WHEN** 半径内のバス停が11件以上ある
- **THEN** 一覧は近い順に10件までを返す

#### Scenario: 半径内のバス停がない
- **WHEN** 半径内のバス停が1件もない
- **THEN** 一覧は空のままで成功を返す

### Requirement: 最寄りバス停の選択は徒歩距離で行う

最寄りバス停の選択は、バス停ごとの徒歩ネットワーク上の徒歩距離が最も小さいバス停を返さなければならない（MUST）。直線距離の大小で最寄りを決めてはならない（MUST NOT）。徒歩距離には、出発地から最寄りノードまでの接続区間と、停留所の座標までの接続区間を含める。

#### Scenario: 直線距離が近いバス停と徒歩距離が近いバス停が違う
- **WHEN** 直線距離では前者が近く、徒歩ネットワーク上の距離では後者が近い
- **THEN** 選択は徒歩距離の近い後者のバス停を返す

#### Scenario: 最寄りバス停の距離が経路検索と一致する
- **WHEN** 経路検索の従来経路が最寄りバス停までの徒歩距離を判定する
- **THEN** その距離は最寄りバス停の選択と同じ徒歩距離である

### Requirement: 半径一覧の半径は直線距離

半径一覧の半径は、指定した座標からバス停までの直線距離として扱わなければならない（MUST）。経路検索の乗降候補に適用される徒歩距離の上限とは、値と意味が別である。半径一覧の判定に徒歩ネットワークを使ってはならない（MUST NOT）。

#### Scenario: 直線距離での判定
- **WHEN** バス停までの直線距離が指定した半径とちょうど同じである
- **THEN** そのバス停は一覧に含める

#### Scenario: 徒歩距離の判定と区別する
- **WHEN** 経路検索の候補絞り込みが徒歩ネットワーク上の距離で判定する
- **THEN** 半径一覧の判定は直線距離のままであり、同じ判定結果にならなくてよい
