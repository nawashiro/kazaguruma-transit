# test-infrastructure Specification

## Purpose
テストがローカルでもCIでも同じ前提で回ることを保証する。ねらいは、実行前の暗黙の状態（サーバ起動、ビルド成果物、環境変数、データベース）が存在しなくても、テスト コマンドが作る。

## Requirements

### Requirement: 一発コマンドでテストが完結する

`npm test` は、本番サーバに依存するテストを含めて、事前にサーバ起動やビルドコマンドを実行しなくても完結しなければならない（SHALL）。ビルド成果物が無い場合、テスト実行系が production ビルドを作ってから本番サーバを起動する。

#### Scenario: サーバ未起動・ビルド未作成からテストする

- **WHEN** 3100ポートに対応するサーバが動いておらず `.next/BUILD_ID` も無い状態で `npm test` を実行する
- **THEN** production ビルドが実行され、その後本番サーバが起動して server プロジェクトが完了し、テスト実行後に起動されたサーバは停止する

### Requirement: 本番サーバの取得と解放

テスト実行系は、server プロジェクトの実行前に既存の応答可能な3100サーバをそのまま流用し、無い場合にのみ新しくサーバを起動しなければならない（SHALL）。後始末は、起動したプロセスのみを停止し、流用した既存サーバを止めてはならない（MUST）。

#### Scenario: 既存サーバを流用する

- **WHEN** 応答できるサーバが既に3100で動いている状態で `npm test` を実行する
- **THEN** 新しいサーバは起動せず、テスト後も既存サーバは動いたままである

#### Scenario: 自分が起動したサーバを後始末する

- **WHEN** `npm test` がサーバを起動してテストが完結する
- **THEN** テスト終了後、そのサーバは停止し、3100ポートは解放される

### Requirement: 環境変数とモックの前提をコマンドが固定する

テストコマンドは実行環境の `NODE_ENV` に依存せず動作しなければならない（SHALL）。コンポーネントテストでルータに依存する選択器（DestinationSelector・OriginSelector）は、手動モックファイルから供給し、テスト側でモックファクトリを書かせてはならない（MUST）。

#### Scenario: NODE_ENV=production の環境でテストする

- **WHEN** `NODE_ENV=production` が設定された環境で `npm test` を実行する
- **THEN** テストは環境変数の値によらず完結する

### Requirement: 依存しないテストの並列実行

本番サーバに依存しない unit テストは並列実行でき、server プロジェクトでは実行順序を保てるようになければならない（SHALL）。unit プロジェクトは本番サーバ依存のテストを実行してはならない（MUST）。

#### Scenario: 分割されたプロジェクトの検出

- **WHEN** `npm test` を実行する
- **THEN** 本番サーバに依存するスイートの全部が server プロジェクトで実行され、unit プロジェクトでは実行されない

### Requirement: テスト用データベースをコマンドが用意する

テスト実行系は、`transit-config.json` の `sqlitePath` が指すデータベースの親ディレクトリとスキーマを実行前に用意しなければならない（SHALL）。データベースファイルが既に存在するときは、それに対してスキーマの適用を行ってはならない（MUST）。

#### Scenario: fresh checkout から server テストを実行する

- **WHEN** `transit-config.json` の `sqlitePath` が指すデータベースファイルが存在しない状態で server プロジェクトのテストを実行する
- **THEN** 親ディレクトリが作られ、Prisma スキーマが適用された空のデータベースが作成されたうえで、本番サーバが起動してテストが完結する

#### Scenario: 既存データベースをそのまま使う

- **WHEN** `sqlitePath` が指すデータベースファイルが既に存在する状態でテストを実行する
- **THEN** スキーマの適用は行われず、そのデータベースの内容は変えられない
