# UI Contract: AIエージェント向け経路案内

## 位置

- 対象: トップページ (`/`)
- 位置: 「※このサービスは非公式のもので、千代田区とは関係ありません」を含む既存カードの直後

## 表示契約

| 要素 | 契約 |
|------|------|
| 操作見出し | 表示文言は正確に `AIエージェントのかたへ`。標準の開閉操作として利用できる。 |
| 初期状態 | 案内本文は全体が非表示である。 |
| 開閉 | 見出しのクリック、タップ、キーボードによる標準操作で表示・非表示を切り替えられる。 |
| 開閉状態 | 支援技術が展開・折りたたみ状態を把握できる。 |
| 本文 | 聞き取り、座標調査、検索結果リンクの3段階を一つのまとまりとして表示する。 |
| URL形式 | `https://kazaguruma-transit.nawashiro.dev/routes?origin={lat}%2C{lon}&destination={lat}%2C{lon}&time={YYYY}-{MM}-{DD}T{hh}%3A{mm}&isDeparture={boolean}&prioritizeSpeed={boolean}` を変更せずに提示する。 |
| 狭い画面 | 375px幅でも本文およびURL形式を横方向のスクロールなしに閲覧できる。 |

## 非対象

- カード自体が座標検索、経路検索、URL生成を実行すること。
- 既存の経路検索条件や保存済み設定を変更すること。
