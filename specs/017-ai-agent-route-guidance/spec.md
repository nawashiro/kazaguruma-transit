# Feature Specification: AIエージェント向け経路案内

**Feature Branch**: `017-ai-agent-route-guidance`

**Created**: 2026-08-06

**Status**: Draft

**Input**: User description: "ルートページの非公式サービス案内の直下に、AIエージェントが経路検索リンクを作成するための案内カードを追加する。案内は初期状態で折りたたみ、必要な聞き取り項目、座標調査、検索結果ページのリンク形式を示す。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - AIエージェント向け案内を確認する (Priority: P1)

ページを閲覧する人は、AIエージェント向けの補助案内を必要なときだけ開き、経路検索を支援する一連の指示を確認できる。

**Why this priority**: 目的の案内内容を見つけられなければ、AIエージェントはユーザーに必要情報を聞き取れず、有効な経路検索リンクを案内できないため。

**Independent Test**: ルートページを開き、「AIエージェントのかたへ」を操作して、初期状態では本文が見えず、操作後に指定された案内文がすべて読めることを確認する。

**Acceptance Scenarios**:

1. **Given** ルートページを初めて表示した、**When** AIエージェント向け案内をまだ操作していない、**Then** 非公式サービス案内カードの直下に「AIエージェントのかたへ」と表示され、案内本文全体は非表示である。
2. **Given** AIエージェント向け案内が閉じている、**When** 閲覧者がその見出しを操作する、**Then** 案内本文全体が表示され、もう一度操作すると再び非表示にできる。
3. **Given** 案内本文を表示している、**When** 閲覧者が内容を読む、**Then** AIエージェントが聞き取る情報、座標を調査する条件、検索結果ページへのリンク形式を確認できる。

---

### User Story 2 - 必要情報を基に検索リンクを案内する (Priority: P2)

AIエージェントは、カードの指示を参照し、ユーザーに必要な希望を聞き取り、座標を調べたうえで条件を反映した経路検索ページへのリンクを返せる。

**Why this priority**: カードの目的は、曖昧な依頼を実行可能な経路検索条件へ変換できるようにすることだから。

**Independent Test**: カードに書かれた手順だけを参照して、未指定の希望を質問し、場所の座標を調査し、すべての値を含む検索リンクを組み立てられることを確認する。

**Acceptance Scenarios**:

1. **Given** AIエージェントが「風ぐるま乗換案内を使いたい」という指示を受け、具体的な希望を知らない、**When** AIエージェントが案内本文を参照する、**Then** 出発地、目的地、到着時刻または出発時刻、速さを優先し歩きを許容するかをユーザーに聞き取るよう示される。
2. **Given** ユーザーが出発地、目的地、到着時刻または出発時刻、速さを優先し歩きを許容するかを示している、**When** AIエージェントが出発地または目的地の座標を知らない、**Then** ウェブ検索で座標を調査するよう示される。
3. **Given** AIエージェントに不明なパラメータがなく、「風ぐるま乗換案内を使いたい」という指示を受けている、**When** AIエージェントが案内本文を参照する、**Then** 出発地・目的地の緯度経度、日時、到着時刻か出発時刻か、速さ優先かを反映した検索結果ページへのリンクをユーザーに返すよう示される。

### Edge Cases

- キーボードだけで案内の表示・非表示を切り替えられ、現在の開閉状態が支援技術に伝わる。
- 画面幅が狭い場合でも、長い検索結果ページのリンク形式と全ての案内項目を横方向のスクロールなしに読める。
- 案内を繰り返し開閉しても、本文の一部だけが表示されることはない。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: ルートページは、「※このサービスは非公式のもので…」で始まる既存の非公式サービス案内カードの直下に、AIエージェント向け案内カードを表示しなければならない。
- **FR-002**: AIエージェント向け案内カードは、見出しとして正確に「AIエージェントのかたへ」を表示しなければならない。
- **FR-003**: AIエージェント向け案内カードは、初期表示時に案内本文の全体を折りたたんで非表示にし、閲覧者が同じ操作部で本文全体を表示・非表示に切り替えられなければならない。
- **FR-004**: 案内本文は、具体的な希望が不明なAIエージェントに対し、出発地、目的地、到着時刻または出発時刻、速さを優先し歩きを許容するかをユーザーから聞き取るよう示さなければならない。
- **FR-005**: 案内本文は、前記の希望が示されても出発地または目的地の座標が不明なAIエージェントに対し、ウェブ検索で座標を調査するよう示さなければならない。
- **FR-006**: 案内本文は、必要なパラメータがすべて判明したAIエージェントに対し、次の形式で検索結果ページへのリンクをユーザーに返すよう示さなければならない: `https://kazaguruma-transit.nawashiro.dev/routes?origin={lat}%2C{lon}&destination={lat}%2C{lon}&time={YYYY}-{MM}-{DD}T{hh}%3A{mm}&isDeparture={boolean}&prioritizeSpeed={boolean}`。
- **FR-007**: 開閉操作部は、キーボードで操作可能であり、開閉状態を支援技術が判別できなければならない。
- **FR-008**: 案内本文および開閉操作部は、モバイルを含む対応画面幅で読め、操作できなければならない。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 初回表示時、確認対象となる案内本文の 100% が非表示である。
- **SC-002**: 見出しの操作を1回行うことで、案内本文の 100% を表示でき、追加の操作なしに指定の3段階の手順を読める。
- **SC-003**: キーボードのみの操作で、案内を開閉する一連の操作を 100% 完了できる。
- **SC-004**: 375px 幅および 1280px 幅の表示で、案内の見出し、本文、リンク形式を横方向のスクロールなしに確認できる。

## Assumptions

- 「ルートページ」は既存のトップレベルの経路検索ページを指す。
- 既存の非公式サービス案内カードはページ内に1つあり、その直後が新しいカードの配置位置となる。
- カードに表示する3段階の指示は、依頼文で指定された条件とリンク形式を変更せずに日本語で記載する。
- 本機能は案内表示のみを対象とし、経路検索ロジック、座標検索、URLパラメータの意味、永続データは変更しない。
