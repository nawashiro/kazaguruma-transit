# データモデル: 施設ページと検索フォームのURL整理

## 公開用施設スナップショット

| 項目 | 内容 | 検証 |
|---|---|---|
| `locationsDataVersion` | 施設データの設定済み版 | 空文字を拒否する |
| `generatedAt` | 生成時刻 | ISO 8601形式 |
| `categories` | 詳細付き施設カテゴリ | IDの一意性、表示名、施設配列を検証する |
| `suggestionCategories` | トップ候補カテゴリ | 表示名と候補座標を検証する |

成果物は`src/generated/location-data.json`である。生成が成功したときだけ全体を置換する。閲覧中に更新しない。

## 施設カテゴリ

| 項目 | 内容 | 検証 |
|---|---|---|
| `id` | URLに使う元の`category:en` | 空、前後空白、制御文字、URL区切り文字、`.`、`..`、`location-detail`、重複を拒否する |
| `name` | 日本語のカテゴリ表示名 | 空文字を拒否する |
| `locations` | 所属施設 | 空配列を許可する |

`id`は正規化しない。リンク境界だけでURLエンコードする。

## 施設

| 項目 | 内容 | 検証 |
|---|---|---|
| `id` | 詳細URLの識別子 | 全カテゴリを通じて一意。既存の許容文字範囲を維持する |
| `name` | 表示名 | 文字列 |
| `lat`,`lng` | 座標 | 有限値、緯度-90〜90、経度-180〜180 |
| `areaName` | 町字表示 | GeoJSONで判定。判定不能時は`地域不明` |
| `description`,`imageUri`,`uri` | 任意の表示情報 | 欠落で施設を除外しない |
| `nodeCopyright`,`imageCopyright`,`descriptionCopyright`,`licence`,`licenceUri` | 帰属情報 | 既存の必須・任意の契約を維持する |

## トップ候補

| 項目 | 内容 | 検証 |
|---|---|---|
| `categoryName` | `optgroup`の表示名 | 文字列 |
| `name` | `option`の表示名 | 文字列 |
| `lat`,`lng` | 選択時に目的地へ設定する座標 | 施設と同じ座標検証 |

候補はIDを持たず、カテゴリ横断で同名・同座標があり得る。名称を一意キーにしない。

## 入力条件

| 項目 | 表現 | 状態 |
|---|---|---|
| `origin`,`destination` | `緯度,経度` | 未指定、有効、不正 |
| `time` | `YYYY-MM-DDTHH:mm` | 未指定、有効、不正 |
| `isDeparture`,`prioritizeSpeed` | `true`または`false` | 未指定、有効、不正 |

入力ページは未指定を許可する。結果ページは全項目を要求する。項目別エラーは不正値だけに付ける。

## 表示状態

- **再入力中**: 地点の候補選択・名前検索・GPS操作を表示する。
- **確定済み**: 地点の住所または座標を表示し、「なおす」を表示する。
- **距離順**: カテゴリページ内だけの一時状態。URLや永続領域へ保存しない。
